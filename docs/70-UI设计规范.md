# VisionGuard 统一 UI 设计规范

负责：VisionGuard 统一 UI 设计规范。不负责：其他模块事实、任务状态或重复验证记录。更新时机：该主题源码或约束变化时；历史发行说明只纠正事实，不随当前版本改写。


全部产品界面采用现代简洁的中性灰底色与青色主色：Windows 视觉节点、Web 主控制台与冻结维护的旧 Android 控制台、Android 相机推流节点和通知节点，包括账号、设置、弹窗、菜单及异常状态。统一服务没有独立图形页面，其 Web 入口共用控制台。启动器提示与内部托盘沿用同一主题；系统权限、文件选择和通知区域遵循平台系统外观。所有组件共用 `icon/visionguard-icon-master.png` 的青色盾牌镜头品牌图标；`scripts/generate-icons.py` 仅缩放、居中与导出平台格式。Android 自适应图标使用中性深灰底色与透明前景安全区，不按组件换色。

## 颜色与主题

使用语义变量，业务页面不再自行定义另一套颜色。Web、Windows、相机与通知节点提供跟随系统／浅色／深色，保存本机用户选择，登录页同样适用；手动模式不被系统切换覆盖。系统状态不可用或设置损坏时默认跟随系统并回退浅色。Windows 7 无现代主题设置时回退浅色；高对比度始终优先系统调色板。Android 系统栏文字随当前模式更新并保留安全区；相机降低窗口亮度与主题独立。画面预览、选区和遮罩保持采集语义，编辑工具栏遵循主题。

|---|---|---|
| 页面 | `#F5F5F5` | `#121212` |
| 面板 | `#FFFFFF` | `#1B1B1B` |
| 次级表面 | `#EEEEEE` | `#282828` |
| 正文 | `#202020` | `#F2F2F2` |
| 辅助文字 | `#626262` | `#B3B3B3` |
| 边框 | `#DDDDDD` | `#3D3D3D` |
| 主色、成功 | `#087F83` | `#4FBCC1` |
| 主色上的文字 | `#FFFFFF` | `#062E30` |
| 选中背景 | `#EDEDED` | `#303030` |
| 选中背景上的文字 | `#07666A` | `#75D2D6` |
| 警告文字 / 表面 | `#805500` / `#FFF1D6` | `#F4CC79` / `#3B3020` |

页面、面板、次级表面、正文、辅助文字、边框和选中背景使用 RGB 三通道相同的纯中性灰。青色用于主操作与强调，背景不带灰绿色偏色。

状态用文字、图标和颜色共同说明：连接成功与主操作用青色，离线与辅助用灰色，等待及未就绪用琥珀色，报警、失败和危险操作用红色。普通文字与所在表面的对比目标至少 4.5:1；文字链接使用选中背景文字色，覆盖页面、面板和悬停表面。危险填充按钮使用浅色白字、深色 `#431B18`。不能把深色主色按钮配白字。禁用控件保留可读标签，并在相关上下文解释原因。

## 字体、间距与控件

- 使用平台中文无衬线字体，不引入远程字体。标题与主操作用中等加粗，其余常规字重。
- 标题 20 / 28、分区 16 / 24、正文 14 / 20、标签 14 / 20、辅助 12 / 18（字号 / 行高）；Android 使用 sp，Web 使用 px，Windows 使用独立于 DPI 的逻辑像素。桌面密集表格允许 14 / 20 正文。
- 间距使用 4 / 8 / 12 / 16 / 24 / 32；页面边距手机 16、桌面 24–32。按钮和输入框圆角 8、卡片 8、弹窗 16；Android 大尺寸底部面板允许 24。
- 轻边框、平面表面；避免装饰渐变、发光、持续呼吸动画与重阴影。只有真实状态、选择或交互反馈才突出显示。
- Android 按钮、返回和图标操作触点至少 48；Web 与 Windows 桌面按钮、输入框至少 36，点击标签扩展复选触点。高度使用最小值，长文字、大字体及输入法不得遮住主操作。
- 输入框有明确标签，密码采用对应键盘和自动填充语义；占位符不能代替标签。表单错误紧邻操作，加载有明确文字。
- 每个控件检查正常、悬停（支持鼠标的平台）、按下、选中、禁用和键盘焦点。普通模态弹窗有标题、取消、返回或 Escape 关闭；关闭后恢复焦点。危险操作先确认，取消为默认安全动作。通知节点强提醒保持仅通过确认停止关闭，不能用返回键或点外部停止声音。
- 列表、详情与弹窗承载字段契约内的节点名、来源名及错误文字；能滚动，不用固定高度裁切正文。输入边界见下方规则。空、加载、失败、断线、缺权限与未配置均有真实提示。

## 本地预览与数据边界

所有组件连接本地服务检查 UI 时，使用独立临时账号、数据目录和模拟数据，通过真实组件的列表、详情、表单和弹窗检查显示。启动器与托盘等入口使用对应临时状态；不支持的节点类型或页面不伪造为已实现。数据生成和注入只作用于本地预览实例，不复用真实账号、配置、记录、视频或声音接收设备。一次性数据与工具保存在被忽略的本机目录，预览结束后关闭模拟客户端和本次服务，按需清理临时数据并保留必要截图与证据。

- 数据至少覆盖正常、空、加载、离线、暂停、异常、无权限及字段允许的上下界；按组件已有能力选择场景。模拟名称、摘要与截图明确标识，合成报警和回执不作为真实采集、推理、收件或声音证据。
- 每个展示字段先确定长度、取值范围、数量和计量方式，再设计输入与布局。现有节点名、来源名的服务端长度上限均为 64 个 UTF-16 单元；各端生成器与自定义输入应遵循同一契约。后续需要收紧时，同步相关端与服务端，不能只在页面改一个上限或将规范目标写成已实现。
- 自动生成名称保持简短，预先为类型与序号后缀留出长度；不直接拼接任意长的机器名、窗口标题、文件路径或完整标识。自定义名称去除首尾空白，拒绝空名称、禁止字符和超限值；输入时说明限制，保存时再次校验，服务端拒绝绕过客户端的无效值。用户输入不得静默截断后保存。
- 数值在输入与保存阶段校验范围、精度和非有限值；列表、标签与选择集合有明确数量及总长度上限。错误与摘要使用有界短文，原始长详情放日志或可展开详情，不挤入名称和状态列。
- 显示层仍须处理合法上限的中文、连续英文、数字与混合文字：列表可省略并提供完整值入口，详情换行或局部滚动，按钮与关键状态不得被挤出。超限输入应被拒绝，不能为了检查长文字而把无效名称写进业务数据。

本地模拟仅用于 UI 层检查；业务逻辑整体链路验收须连接[真实服务器独立测试通道](60-构建验证与发布.md#真实服务器独立测试通道)，由真实组件完成，不在本地构造模拟链路。各端是否完成生成、输入和保存校验，以及真实页面是否目检通过，以[任务清单](06-任务清单.md)和[验证记录](90-验证记录.md)为准。

## 图标

功能图标统一使用 [Lucide](https://lucide.dev/) 官方线性图形，各端固定为 `1.49.0`，与 Web 的 `lucide-react` 一致。不得手绘、用 emoji 或字体字符代替，也不混用其他图标家族。品牌 Logo、启动图标、采集画面与系统控件保留各自用途。

- 使用 24 × 24 坐标、线宽 2、圆端点与圆连接；常规显示 24，桌面紧凑控件可用 16 或 20，按完整坐标等比缩放。图标随正文、辅助或状态语义色变化，不单独加渐变、阴影或装饰底色。
- 返回、展开、添加、删除及同类状态采用同一图形。返回和方向导航支持 RTL 镜像；车辆、铃铛等物体图标不镜像。图标触点遵循平台按钮最小尺寸，缩小图形不缩小触点。
- 只有图标的操作有无障碍名称或提示；旁边已有等义文字时图标作为装饰。成功、错误和离线保留文字说明，不靠颜色或图标单独传达结果。
- Web 直接引用成熟库；原生端引用 `assets/vendor/lucide/` 的官方 SVG 子集，通过 `node scripts/generate-lucide-icons.js` 机械转换为 Compose、VectorDrawable 和 WPF 格式，不重画轮廓。`manifest.json` 保留版本、来源、逐图校验值与方向镜像规则；更新后用 `--check` 检查生成资源，不依赖目标设备预装图标字体。
- Android 通知小图标使用透明底白色线条 mask：常驻 `bell`、活动报警 `bell-ring`、更新下载 `download`；平台负责最终通知颜色。保留 [ISC 与 Feather MIT 声明](https://lucide.dev/license)：Android 随 assets、Web 随公开静态文件、Windows 随程序集与输出目录分发。

## 页面清单与布局

| 组件 | 必查页面及覆盖范围 |
|---|---|
| Windows 视觉节点 | 主窗口与导航、监控来源卡和参数、账号与全局设置、窗口选择、采集选区、遮罩编辑、退出/清空/异常等提示、托盘菜单、启动器更新与错误提示 |
| Web 控制台 | 登录、节点搜索/筛选与详情、来源状态/参数/回执、设备重命名/关联/解绑确认、事件列表与截图详情、通知范围及离线来源、时间标准与账号改密/退出 |
| Android 控制台 | 登录与账号条、警报列表/筛选/详情/截图、设备列表/来源/参数/解绑确认、连接状态与登录高级服务地址、统一时间显示、所有底部面板与弹窗 |
| Android 相机推流节点 | 登录、目标视觉节点选择、预览/收起、规格、开始/停止、独立亮度降低、三种主题、更新、权限/连接/前后台状态、账号与改密 |
| Android 通知节点 | 登录、接警/连接/接收范围/最近事件、三种主题、更新、声音策略、历史/清空、铃声库/录音/导入/默认/重命名/删除、权限提示、全屏报警与确认停止 |

Web 桌面作为唯一主要控制台，最小布局宽度 1040，始终左导航＋右内容；来源表格局部滚动，不投入手机 Web 布局。旧 Android 控制台仅维护回归，不进入未来默认发行。相机与通知节点继续适配手机、平板、旋转和安全区。Android 保留各自任务与导航，采用同一套控件和状态规范。Windows 保留采集与推理工作流，统一主题与操作反馈。

正式运行仅展示实际连接、配置和记录；本地 UI 预览使用上述明确标识的模拟临时数据，未上报的值标记为未报告。来源运行时不能修改的参数说明停止条件。通知收件只表示保存，不能显示为已播放；过期事件不重新通知。布局改造不得改变上述业务语义。

## 实现入口与核验

- Android 共用主题：[`VisionGuardTheme.kt`](../android-shared/src/main/java/com/xgwnje/visionguard/account/VisionGuardTheme.kt)，各端通过本机主题入口复用，组件细则见[Android UI 规范](./71-Android界面规范.md)。
- Web 变量与控件：[`style.css`](../receiver/web/src/style.css)、[`main.tsx`](../receiver/web/src/main.tsx)。
- Windows 资源与窗口：[`DarkTheme.xaml`](../detector/windows-wpf/Themes/DarkTheme.xaml)、[`Views/`](../detector/windows-wpf/Views)；文件名不表示只支持深色。

逐页核验颜色、文字、间距、形状、全部交互态和上述边界，并检查浅深色、窄屏/旋转、大字号、键盘及长内容。自动检查负责语法、主题契约、颜色对比与构建；真实窗口和设备目检单独判断。全部当前结果、失败与未覆盖项只在[验证报告](90-验证记录.md)维护，一次性素材保存在被忽略的 `.local/`。

运行 `node scripts/check-ui-theme.js` 核对三端实际颜色与规范、中性色 RGB 约束、正文/按钮/状态文字对比和 Android 主题复用；该检查已接入开发 CI，不能代替真实页面目检。

组件尺寸与页面组合见[多平台 UI 组件设计](72-多平台UI组件设计.md)。

## 精修紧凑型交互验收

主导航保留现有任务，当前节点、来源名与状态放在对应操作旁。列表行使用 8–12 间距，分区使用 16；桌面常规表单 36 高，Android 48 触点。正文 14，Android 长文本与输入可保留 16；不缩小报警内容来增加密度。低频连接信息、权限说明与安装说明进入相关设置或展开区，首页不重复堆放说明。

Android 主题选项使用整行触点，窄屏和大字号不能把选项文字挤成多行；外观与更新入口放在共用选项行。通知首页的服务地址和时间标准进入连接详情；相机入队、服务收帧与丢弃统计使用明确标签。Web 账号表单的复选框与标签同排，保留点击范围与焦点。

参数默认阅读态，每项单独编辑、还原当前值、取消和保存。Windows 置信度 10–95% 整数，对应协议 0.10–0.95、步长 0.01；采样 1–5 FPS 整数，冷却 1–300 秒整数。模型只列节点报告的可用模型。目标由实际模型标签提供中文搜索多选，至少一项；完整标签列表滚动显示，协议列表上限 4096 字符，超限拒绝而不截断。未知或未下载模型明确不可用，不能推测标签。

Web 草稿按账号、节点与来源隔离，断线和切换来源保留，退出清除。模型变化保留草稿并要求重新核对目标。提交时冻结该项重复操作；服务器接收或转发只显示等待，执行端 completed 成功才显示已保存。超时或断线显示结果待核实，失败保留草稿；后到的当前请求结果可以纠正状态，旧连接不得写入新会话。Windows 草稿与实际设置独立，保存成功才读回，失败回退并显示原因。

键盘 Tab 顺序跟随阅读顺序，焦点清晰可见；数值表单 Enter 提交，Windows Ctrl+Enter 保存、Escape 取消。弹窗关闭恢复调用位置焦点，危险确认默认取消。每页检查浅色、深色、系统跟随、长名称、空态、无权限、断线、忙碌、失败、成功；Android 另检查系统栏、大字、横屏与键盘。Windows 高对比度和 Win7 回退分别判断。所有页面均按上方清单验收，不新增示意图里但产品未实现的功能。

## 设计资源管理

长期采用的图片与预览资源独立放 `docs/assets/`，业务代码不引用文档素材。官方图标源继续放 `assets/vendor/lucide/`，品牌母版继续放 `icon/`；不移动运行时所需资源。一次性探索和未采用原型只留本机忽略目录。
