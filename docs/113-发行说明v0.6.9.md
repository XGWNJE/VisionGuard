# VisionGuard v0.6.9

负责：本版发行范围和安装说明。不负责：完整验证报告。更新时机：本版发行内容变化时。

## 本版内容

- 全部组件统一采用扫描人应用图标：实心头部、三条等厚圆弧横纹、四角扫描框与橙色扫描线。Windows 视觉节点、启动器 / 驻留 / 托盘、Android 相机 / 通知节点及 Web favicon 共用同一图形。
- Android 自适应图标保留扫描框安全区，并接入系统单色主题图标；启动器的更新与提示窗口显式显示应用图标。
- 保存 SVG、透明 / 多尺寸 PNG、字标、圆形 / 圆角方形与多帧 ICO 物料，加入品牌导出一致性 CI。界面中性灰 / 青色主题和 Lucide 功能图标保持现有规范。
- 本版发行 Windows 视觉节点、Android 相机与通知节点，以及统一服务 / Web；旧 Android 控制台继续退役，历史 0.6.0 下载元数据保留。

## 安装与检查

从本版发行页更新三个客户端；Web 刷新[线上控制台](https://visionguard.xgwnje.cn/console/)，检查浏览器标签页图标。Windows 检查程序、任务栏及托盘；Android 检查桌面图标，支持系统主题图标的桌面可检查单色造型。

本版不包含通知节点锁屏收件问题修复，也不改变业务协议。构建、附件与公网检查的覆盖边界见[验证记录](90-验证记录.md)；真实设备图标观感、完整报警链与长时运行由 owner 单独验收。
