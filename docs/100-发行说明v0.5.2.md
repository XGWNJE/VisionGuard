# VisionGuard 0.5.2

负责：本版发行内容与历史事实。不负责：其他模块事实、任务状态或重复验证记录。更新时机：该主题源码或约束变化时；历史发行说明只纠正事实，不随当前版本改写。


所有组件统一采用黑白灰底色、青色主色和 Lucide 功能图标。应用显示名统一为视觉节点、相机推流节点、控制台、通知节点、统一服务；各端共用青色盾牌镜头应用图标。

- Windows 视觉节点包含统一启动器、modern / legacy 推理运行时和后台驻留；Android 相机推流节点负责前台摄像头推流。
- Web 与 Android 控制台管理设备、来源、事件和通知范围；独立通知节点负责后台接警、声音队列和告警记录，新增独立签名发行包。
- 统一服务与 Web 控制台一同部署，客户端发行包在本页下载。
- 服务使用独立 Node.js 24 运行时，并更新上传及请求解析依赖；生产依赖扫描无已知漏洞。

本版属于内测架构更新，旧 4.x 协议与配置不兼容。旧 Android 安装的版本号高于 0.x，不能直接覆盖降级；应在保留所需数据后重新安装，当前 0.x 安装可以正常更新。通知节点当前通过下载安装，尚未提供应用内自动更新。

验证范围与仍未覆盖的场景见仓库的 `docs/90-验证记录.md`。
