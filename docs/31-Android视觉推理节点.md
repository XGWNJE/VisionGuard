# Android 视觉推理节点

负责：Android 视觉推理节点的实现事实与平台限制。不负责：任务状态或验证报告。更新时机：实现或约束变化时。任务归属见[任务清单](06-任务清单.md)，界面规范见[几何空间界面规范](73-几何空间界面规范.md)，证据及未覆盖项见[验证记录](90-验证记录.md)。

## 工程与身份

`detector/android-inference/` 是独立 Compose 应用，显示名“视觉推理节点”，包名 `com.xgwnje.visionguard.inference`。与相机推流、通知应用分别安装、保存账号及设备身份，共用 `android-shared/` 的账号、主题和官方 Lucide 资源。两份推理实现的正式包名相同，比较安装使用各自隔离预览包。

登录组件 `android-inference`，协议身份 `detector / visual / android`，不签发 Windows 驻留子会话。只执行推理、不发布视频；本机相机由 CameraX 采集，远程镜头经统一服务 `/media/ws` 订阅，不另建服务或控制台。

## 来源与检测

检测链：`Capture → MaskApply → Letterbox → ONNX Runtime → Parse → AlertDecision → Outbox`。

- 本机来源固定为 `camera`；绑定的远程镜头通过 `stream-list` 自动加入、移除，来源标识稳定。服务下发来源上限 1–16；每路独立运行与报错，忙时保留最新帧。
- 来源名最多 64 个 UTF-16 单元且无控制字符；置信度 10–95% 整数、采样 1–5 FPS、冷却 1–300 秒、COCO 英文目标最长 4096 字符。模型与参数停止后保存，下次启动生效，本机及远控共用校验。
- 遮罩用 `[0,1]` 相对坐标，推理前涂黑；预览和截图复用已遮罩画面，遮罩不通过远控同步。
- 从统一服务按需下载 YOLO26 n / s / m 的 320 / 640 六个模型到私有 `files/models/`，长度校验后替换。等比缩放补黑边，输入 CHW RGB `/255`；默认尝试 NNAPI，注册或会话创建失败回落 CPU 并保留原因，intra / inter 线程为 2 / 1。
- 解析验证输出展平长度，识别 `[1,300,6]`（模型内 NMS）或 `[1,84,N]`（解析侧逐类 NMS）。最多返回 5 框，映射回原帧。
- 远程帧格式为 4 字节大端头长、JSON、JPEG：头 ≤4096 字节、JPEG ≤2 MiB、最长 / 短边 ≤1280 / 720、旋转仅 0/90/180/270，声明尺寸须与实际一致。

## 报警、状态与远控

NTP 校正报警时间，逐来源独立冷却。账号 / 服务 / 设备分区的持久 outbox 最多 500 项，超出丢最旧；实时期限 30 秒，过期不补发。收到接受回执后移除事件并异步发送截图（宽 ≤960，JPEG 65）；确定拒收 `alert-id-conflict`、`invalid-or-expired-event` 同样移除，其他拒收保留重试。

心跳每 3 秒上报运行意图 `monitoringExpected`、成功处理时间 `lastProgressAt`、FPS、后端、参数及错误。成功帧才推进进度；FPS 低于目标 80% 连续 30 秒提示性能不足。

控制台复用现有操作入口，命令逐条返回 completed 回执：

- `pause` / `resume` 可指定来源；设备级作用于全部来源，来源不存在时拒绝。
- `set-config` 支持置信度、冷却、目标、采样和模型五个键；运行中拒绝，未指定来源时作用于第一个来源。
- `cache-inspect` / `cache-clean` 回传清理结果；`stop-alarm` 回报“当前无报警”。不接收 Windows 的 `open-detector` / `close-detector`，不声明 `directml`。

## 后台运行

有来源运行时启用 `InferenceService` 前台服务，退后台或锁屏继续推理；运行意图持久化，进程被系统回收后按意图恢复，主动停止清除意图。系统相机权限仍需本机授权，不修改锁屏或唤醒设置；真机后台存活以验证记录为准。

## 界面

按[几何空间界面规范](73-几何空间界面规范.md)落地：全屏运行、无顶部标题行，应用级入口在技术信息带右端；窄屏上下堆叠，宽 ≥840dp 或横屏短边 ≥600dp 且字号 ≤1.3 时预览与来源滑架并排，操作台与技术信息带通栏。几何空间界面四批已全部落地：几何组件层（压板操作键、图标键、拨档、滚筒、滑轨、右侧抽屉、信息带、危险确认）、主工作区、来源检查抽屉、添加来源抽屉、参数抽屉（采样滚筒、置信度滑轨、冷却三位滚筒、模型插片与目标五列排片）、遮罩抽屉（26dp 内衬、四角把手、坐标列表与清空闸门）、全局设置抽屉（账号、模型、外观、后台、维护五个分区）与可折叠帮助；旧 Material 界面与工具已删除。全局设置含账号、模型、外观、后台、版本与维护，帮助页解释操作边界；沿用[统一 UI 规范](70-UI设计规范.md)。

账号会话用 Keystore 保存并排除系统备份；来源参数、报警元数据和截图按账号分区。截图缓存限 7 天 / 200 项 / 100 MB，清理不触及模型、账号或配置。

## 构建与未实现项

构建入口为 `.agents/skills/visionguard-build/scripts/build-all.ps1 -Target AndroidInference`，版本读取根 `VERSION`；当前所有 ABI 合入一个 APK。签名所需材料仅放忽略文件或环境变量，构建结果见验证记录。

应用内更新使用 `android-inference` 查询键，正式发布流水线与下载元数据尚未接入，当前没有更新资产。Android 系统画面采集、Windows 窗口 / 驻留机制未实现；后续开发承接由 owner 选定分支，不在存档收尾中扩展。
