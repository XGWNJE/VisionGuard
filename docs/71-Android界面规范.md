# VisionGuard Android UI 规范

负责：VisionGuard Android UI 规范。不负责：其他模块事实、任务状态或重复验证记录。更新时机：该主题源码或约束变化时；历史发行说明只纠正事实，不随当前版本改写。


三个 Android 组件的账号界面、Material 颜色、字号、形状和语义状态共用 [`android-shared/`](../android-shared) 主题。颜色与控件参数以[统一 UI 设计规范](./70-UI设计规范.md)为唯一来源，不另建页面主题。相机与通知提供跟随系统、浅色、深色并保存选择；窗口亮度降低独立于主题。旧控制台冻结维护。

## 共同要求

- 登录页要求账号、密码与本机名称；服务地址放在可展开的测试设置。设备身份由服务签发，不作为用户输入。
- 登录后的账号条显示账号与设备名，长名称换行；退出和修改密码遵循同一弹窗样式。改密说明其他设备需要重新登录。
- 明确定义全部 Material 色槽、on-color、错误与表面颜色，关闭动态壁纸配色；状态颜色从共享语义获取，禁止固定白色卡片和另一套默认紫色。
- 按钮、输入框、返回和图标触点至少 48dp，使用最小高度支持字体缩放；表单保留输入法空间。长列表、设置和弹窗可滚动，底部导航预留系统手势区与内容空间。
- 功能图标采用[统一 UI 规范](./70-UI设计规范.md#图标)指定的 Lucide 官方线性资源；三端共用生成的 Compose 图标、通知白色 mask 与许可证，禁止手绘或混用 Material 图标。
- 卡片使用主题表面与轻边框，形状、字号、间距与 Web/Windows 共用层级。危险操作使用错误色并确认；选中、失败、等待与禁用均有文字。
- 平台权限、系统文件选择、通知栏遵循系统样式；应用内权限解释、接警全屏与声音策略仍遵循主题。系统通知渠道、声音流和后台行为不因视觉改造而调整。

## 各端主任务

- **相机推流节点**：目标视觉节点、实时预览、开始/停止、画面规格、独立亮度降低与外观设置与收起预览。切后台/锁屏正常停止，回前台手动恢复；服务收帧确认不表示推理完成。画面保持真实比例，预览隐藏后状态和停止操作仍可达。
- **控制台**：`警报 / 设备` 两个主入口，列表、截图详情、设备与逐来源参数共用主题；根据节点能力显示控制。离线设备保留登记身份，解绑确认后撤销服务登记，事件记录保留。
- **通知节点**：接警、连接、服务响应、接收范围、声音策略、最近报警和历史；历史与铃声库统一标题/返回/空状态。录音、导入、默认、重命名与删除有明确反馈。全屏报警保留确认停止与有限播放的真实状态，不用装饰动画制造额外警告。

## 核验入口

三个工程按影响运行 `:app:testDebugUnitTest`、`:app:lintDebug` 与 Release 构建。可见模拟器与真实设备按[统一规范页面清单](./70-UI设计规范.md#页面清单与布局)逐项检查；浅深色、大字号、旋转、权限和厂商行为的结果只在[验证报告](90-验证记录.md)记录。构建或静态主题一致不表示真实页面全部目检通过。
