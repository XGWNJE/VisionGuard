# 0.6.2 内测版

负责：本版发行内容、安装方式与已知覆盖边界。不负责：任务进度或重复验证记录。更新时机：本版发布前核对最终内容；发布后只纠正历史事实。

- Windows 视觉节点改为主预览、来源列表、来源检查三个可调宽分区；预览保持画面比例，来源纵向滚动，仅展示配置成功或已绑定的来源，失败的临时手动来源不保留。
- 全局设置移入独立全屏子界面；来源检查按运行状态、检测规则与参数等用途分组。后端、推理耗时和最后报警直接显示在运行状态内，控件尺寸、间距和菜单秩序统一。
- 修正分区拖动边界反馈、检查区宽度调节、选中卡片圆角描边和各分区滚动条留白；布局随窗口空间调整。
- Web、Android 相机与通知节点沿用青色主题和 Lucide 图标，按信息频率与重要程度调整组件；优先使用选择控件，覆盖横竖屏布局及平板交互。
- 相机与服务改为有界连续推送和累计确认，保留丢帧统计；Windows 使用新帧触发与固定节拍限速。相机随来源目标频率发送，暂停检测后降至 1 FPS；YUV 按行转换，保持 JPEG 质量 55。账号状态快照读取不再等待 HTTP 校验，减少推理阻塞。

下载附件包含 Windows 整包、Android 相机推流节点和通知节点三个包。Windows 完整解压后运行根目录 `VisionGuard.Detector.Windows.exe`，内含 modern 和 Windows 7 SP1 x64 legacy 运行时；Android 使用同签名包安装。旧 Android 控制台继续保留源码与必要回归，退出默认发行。统一服务与 Web 一并部署。

本版为内测，不承诺旧协议及数据兼容。构建、单元检查与既有 UI／真实相机验收分别记录，不能替代所有设备、Win7 实机或完整声音报警链验证；覆盖边界见[验证记录](90-验证记录.md)。
