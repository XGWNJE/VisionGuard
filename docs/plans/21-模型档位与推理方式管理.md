# 模型档位与推理方式管理

负责：[待办 21](../06-待办.md) 的 Android 推理端模型管理需求。不负责：实现事实与验证证据。更新时机：需求调整时，完成或取消后随条目删除。未启动，实施时沿用现有全局模型资源与来源检测规则分区。

- 模型档位显性名称统一为 M320、M640；初始没有可用模型配置时，不默认选中任何档位，只有对应模型成功下载后才允许选择。
- 用户下载某档位时，自动下载该档位的 CPU 与 GPU 两种模型；界面不额外解释两类模型的下载与管理机制。
- 根据当前设备环境与推理引擎的实际兼容情况自动确定可用推理方式；环境兼容时默认优先 GPU，不提供推理方式优先级的手动选择项。
- 用户只选择模型档位，具体运行方式由程序自动控制。

完成条件：无模型时无默认选择，未下载成功的档位不可选；每档自动下载两种模型，运行方式按实际兼容性自动确定。
