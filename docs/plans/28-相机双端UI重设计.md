# 28 · 相机双端 UI 重设计

负责：相机双端草稿与后续实施边界。不负责：正式功能事实与验证证据。更新时机：审稿结论、范围或承接状态变化时。

分支：`codex/camera-ui-draft`，从 `main` 承接。静态稿与草稿审计已交，正式 Web / Android 界面等 owner 设计审稿确认后再改。

- 控制优先：横屏左控制右预览，竖屏上控制下预览，启停固定可见；关闭预览保留区域。
- Web 复用控制台官方 shadcn/ui Neutral / Radix Nova；Android 保留 Compose，原生实现同款视觉与交互。
- 基准：手机 360×800 / 800×360、平板 800×1280 / 1280×800，双端浅深色共 16 张主稿；补查 360×640 / 640×360 与 768×1024 / 1024×768。
- 覆盖登录、目标选择、帮助、账号、外观、Android 更新与推流异常。草稿只用固定示例，不连接相机、账号或生产服务。
- 源码：[静态渲染器](../../prototypes/camera-ui-draft/package.json)。先 `npm ci --prefix receiver/web`，再运行渲染器的 `prepare-runtime`、`build` / `dev` 脚本；导出后运行 `scripts/compose.py <导出目录>` 排版。证据见[验证记录](../90-验证记录.md)。
- 审稿确认后按 Web → Android 落地，沿用登录、配置、控制及媒体协议；同步主题检查、相关专题与现有测试。不推送、合并、发布或部署。
