# VisionGuard v0.6.7

负责：本版发行范围和安装说明。不负责：完整验证报告。更新时机：本版发行内容变化时。

## 本版内容

- Web 控制台重构登录、导航、节点目录与工作区、参数、事件、通知范围、设置和账号管理。保留中性灰 / 青色主题与 Lucide 1.49.0，采用紧凑扁平布局；节点主要操作集中在首屏，运行、配置、设备管理和回执分区显示，窄屏提供底部导航。
- Web、Windows 视觉节点、Android 相机与通知节点提供可选“记住账号密码”：默认未勾选，成功登录后加密保存，下次自动填入；取消即清除，退出保留，不新增自动登录。数据按本机组件与服务地址隔离。
- Web 与统一服务增加可关联的 WebSocket 连接 / 认证阶段、超时和关闭诊断，日志排除密码和 token，保留既有认证与重试规则。
- 本版发行范围为 Windows 视觉节点、Android 相机与通知节点及统一服务 / Web。旧 Android 控制台继续退役，历史 0.6.0 元数据保留。

## 实装检查

打开[线上控制台](https://visionguard.xgwnje.cn/console/)检查新布局与实际节点操作；客户端安装本版后，可按[账号密码记忆](60-构建验证与发布.md#账号密码记忆)检查保存、重新打开自动填入及取消清除。

本地模拟界面验收、编译、单元检查和发行附件校验不代表真实节点、完整报警链、声音或持续运行全部通过；实际覆盖与发布状态只见[验证记录](90-验证记录.md)。
