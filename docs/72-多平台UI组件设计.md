# 多平台 UI 组件设计

负责：终端组件尺寸、组合方式与页面布局。不负责：业务逻辑、协议、任务状态与重复验证报告。更新时机：共享组件或页面布局变化时。颜色和图标以[统一规范](70-UI设计规范.md)为准，设备行为仍由各模块负责。采用 owner 选定的第 2 套“画面优先”方向：沿用中性灰与青色主题，以频率和重要程度组织内容，拉开关键状态、主操作与辅助信息层次；示意图不作为业务事实。

## 页面组合

### Web 控制台

按 owner 本轮授权采用简洁、有序、紧凑、扁平的工具型布局，保留中性灰 / 青色和同版本 Lucide。桌面侧导航 144–164px、节点目录 208–240px，与工作区并列；主导航移除顶部品牌标题、底部账号快捷入口及重复标题，保留功能菜单与原有账号权限；不足 1040px 时侧导航缩为 72px。竖屏与窄视口使用底部导航、目录 / 详情切换和返回全部节点。以实际 CSS 视口适配 8.8 寸平板；桌面控件至少 36px，触屏及窄视口至少 48px，保留安全区和键盘空间。

节点、事件、通知范围和设置共用屏幕可用高度与页边距，面板边界延伸到共同底部，整页不随内容拉长；长列表与配置在各自分栏内滚动，窄屏保留底部导航安全区。账号在线 / 检测 / 推流 / 最近事件概览收在节点目录顶部的两列紧凑信息块，不再横跨详情上方。节点目录与详情等高，目录列表与较长详情分别滚动，窄屏目录 / 详情切换后仍在当前面板内滚动。节点工作区顶部直接呈现身份、连接 / 工作状态、控制对象和能力允许的启停、报警确认、应用操作；节点顶部采用身份 / 状态与右侧主要操作的首行，下方信息行集中控制对象、组件状态和最近响应，取消嵌套卡片边框；较窄工作区让操作自然换行，下方使用运行、参数与配置、设备管理三个标签页。最近事件与操作回执在节点详情内右栏分成上下独立板块，与节点顶部对齐，切换详情标签时仍保留；详情内容区不超过 785px 时移到内容下方。运行区保留来源与节点对应的推流 / 接收上下文；窄屏来源改为紧凑行，名称、状态、实际帧率与启停 / 参数操作一起显示。相机运行区呈现推流关联，通知节点提供接收范围及编辑入口；未报告内容明确标注。历史事件画面不能冒充实时视频。

参数使用阅读行与逐项编辑，来源入口直接定位当前来源配置；模型、滑块、冷却预设、FPS 档位及中文目标多选沿用现有契约。工作区切换保留草稿，控制对象明确展示，保存以执行回执为准。标签支持方向键 / Home / End 移动焦点、Enter / Space 切换。

事件使用带筛选的紧凑行与右侧截图抽屉，保留关闭 / Escape / 返回焦点。事件列表独立滚动，筛选区保留在上方；筛选区超过可用高度时也可局部滚动。搜索、类型与起止时间共同筛选已加载的最近最多 100 条事件；时间按账号的北京时间或 UTC 解释，允许只填一端，结束时间包含该秒，起止倒置时提示错误。清除时间不影响搜索 / 类型；退出账号或切换时间标准清空时间条件。通知范围采用通知节点目录与独立编辑区，两区分别滚动，切换节点保留草稿，范围选择与保存操作在编辑区滚动时保持可见，离线来源在辅助展开区。设置页左侧账号与本机，右侧常规设置（外观 / 统一时间）与缓存；沿用节点 / 事件 / 通知范围页的全宽内容与页边距，采用等宽双列和对齐的字段 / 操作列，每个设置面板独立滚动；内容宽度不超过 1040px 使用账号与本机 / 常规设置 / 缓存分区切换，保留未提交的字段草稿，560px 内标签移到字段上方。操作列统一 112px，密码框与名称框左侧对齐，保留必要提示；外观选择沿用主按钮的青色选中样式。账号管理先看列表，创建和管理使用弹层。登录页采用居中的紧凑表单，仅保留文字品牌、登录标题、账号密码、记忆选项与登录操作；删除宣传语、功能介绍和重复说明，暂不放品牌图形及功能图标，错误按需显示。外观保留跟随系统 / 浅色 / 深色分段选择，登录页使用纯文字选项，选择器与表单共用面板底色和细边框，选中项使用主按钮的青色填充。所有页面保留空态、错误、禁用原因和危险操作确认。

### Windows 视觉推理节点

真实 WPF 主窗为左侧主预览、中间全部有效来源的纵向卡片、右侧来源检查；移除应用内品牌／连接顶栏、底部来源条和预览勾选。点击来源同步主画面与检查对象，所有来源保留在中间列表。配置草稿先选择窗口或屏幕区域，成功后才入列；取消或失败销毁草稿。已配置来源暂时断流不销毁。无来源显示添加入口，远程绑定由同步消息自动入列。列表虚拟化与可见范围判断只减少位图刷新，不改变推理或报警。主画面保留有界检测标签，列表卡片只保留检测框；画面等比、不裁切，停止保留最后画面并明确标识。

默认 1420×800 DIP、最小 720×480 DIP，按实际工作区适配；900P 是检查场景，不是固定排版标准。来源列宽 240–380 DIP、检查区宽 300–420 DIP；两根分隔条独立调节侧栏，拖动过程就限制边界，主画面获得剩余空间；不足 1080 DIP 时检查区作为侧层展开，列表和检查内容分别滚动。来源卡片按固定 4:3 布局随来源栏宽度调整，高度限制为 156–420 DIP；帧比例与横竖屏只影响卡片内的等比缩放和居中留边。来源检查依次为当前来源、运行状态与启停、常用检测规则、采集范围与遮罩、来源管理；实际帧率、后端、推理耗时和最后报警属于运行状态，直接显示不折叠，目标帧率、置信度和报警冷却属于规则；同组字段基准行高 32 DIP，单操作按钮占所在列宽，采集窗口／选区为等宽双按钮；按来源类型显示合法操作，不留下空配置重置入口。更换目标失败回退，参数整组编辑继续使用独立草稿、取消／还原／保存及运行中只读规则。

来源卡片内层以圆角裁切，外层描边覆盖画面与标题。列表、检查区与全局内容页统一滚动留白：视口至轨道 12 DIP、轨道宽 10 DIP、距分区外沿 8 DIP，滚动条隐藏时保留槽位；全局正文沿用最大 800 DIP 的阅读宽度。

全局设置覆盖当前窗口内容区，左侧五类导航，右侧独立内容：账号与连接、推理与模型、外观、后台运行、版本与维护。登录后隐藏登录输入，维护操作与日常设置分开；返回保留预览选中来源和列表位置。两个区域共用菜单资源：同级控件高 36 DIP、内距 12／4，分组间距 24、字段间距 12、成组间距 8；检查参数标签列 72 DIP，全局标签列 96 DIP、操作列 112 DIP，按钮宽度由所属列决定。长文字使用换行、完整提示或局部滚动，不任意改变控件尺寸。外观三选项等宽，选中状态可见；采样 1–5 FPS、冷却 1–300 秒、置信度 10–95% 的既有边界保留。

窗口选择、采集选区和遮罩仍为专用工具窗口，工具条采用统一尺寸；托盘、启动器错误和确认提示复用现有主题。系统窗口边框、文件选择不重绘。不按概念图调整来源容量、采样范围或检测工作流。

### Android 相机与通知节点

相机主页面仅有控制 / 状态与预览两个区域：手机控制区占一半，平板占三分之一（可用短边至少 600dp，字号不超过 1.3），大字号控制区占一半。横屏左控制右预览，竖屏上预览下控制，区域间距 12dp；关闭预览只在原区域居中显示状态，尺寸和位置不变。正常场景主控件一屏容纳，极短窗口或超大字号保留控制区内滚动与固定启停。通知主页面为接警控制 / 最近报警双区：横屏左控制右记录，竖屏上控制下记录，手机各占一半，平板控制占三分之一（可用短边至少 600dp）；内距与区域间距均为 12dp。常规字号两区各自滚动，接警按钮固定在控制区底部；字号超过 1.3 或竖屏可用高度不足 440dp 时改为单列整页滚动。登录表单最大 480dp 居中，系统栏、安全区和键盘遵循平台。

相机控制区包含账号 / 帮助 / 设置的同尺寸图标入口、独立状态行、入队 / 服务收帧 / 两端丢弃三列统计、共用标签列的目标与规格、等宽规格按钮、等宽亮度 / 预览开关及底部固定启停。主控件触点至少 48dp，行间距统一按高度为 4dp / 12dp，宽松高度下控制组居中；预览开关采用开启语义。解释、完整状态 / 统计 / 来源、采集尺寸与主动未采样计数统一放帮助页；主界面保留实际发送尺寸 / 回退，不堆叠操作提示。预览区只呈现画面或居中状态。

通知顶部同样提供账号 / 帮助 / 设置 48dp 图标入口。两区标题最小高 48dp、水平内距 12dp，标题与状态 / 全部记录共用中心线；控制内容从顶部排列，接收范围与铃声的标签列为随字号缩放的 64dp，字段值和箭头各自对齐。常规控件间距 8dp、水平内距及按钮底部留白 12dp；控制区高度不足 320dp 时，内容间距缩至 4dp、按钮底部留白为 8dp，本次收件 / 服务响应移至帮助，保留 48dp 触点。控制区集中连接状态、重连、系统通知缺权限入口、接收范围、铃声、等宽循环次数 / 铃声库及接警启停；完整范围、连接地址、时间标准、连接统计和收件 / 播放说明在帮助弹窗中查看。最近报警默认最多六条，列表上下内距 4dp、记录上下内距 8dp，显示来源、时间与实际结束方式，并保留全部记录入口；大字号单列显示最近四条。历史、铃声库、录音 / 导入、重命名 / 删除确认复用返回标题、列表行、空状态和弹窗。共用账号、改名、改密与外观入口遵循同一尺寸。

通知告警确认用全屏目标展示：竖屏居中目标名称与位图，宽横屏左图右名称，系统安全区内距 24dp，超大字号保留内容滚动。人 / 汽车的透明 PNG 位于 `notifier/android/app/src/main/res/drawable-nodpi/`，由 imagegen 生成并保留原像素，作为目标示意而非事件画面；功能入口继续使用 Lucide。目标名称为主要文本，短名称 64sp，其他类别与连接中断等事件使用可换行标题。图像柔和浮现 420ms、扫描光带周期 3600ms，系统关闭动画时静态显示。全屏展示区轻点即可调用确认停止，底部仅提示操作；48dp 详情入口消费自身点击，不确认告警。详情另开普通弹窗，关闭返回未确认告警；确认错误始终可见，不替代保存结果。


## 交付与边界

界面覆盖范围（系统文件选择、权限页及安装器继续使用平台控件）：

| 组件 | 页面与控件 |
|---|---|
| 共享 Android | 登录、账号菜单、改名／改密、外观选择、更新进度／取消／安装确认；小屏弹窗正文滚动，主按钮保持可达。 |

| Web 控制台 | 登录、节点筛选／详情／来源／参数／设备管理／回执、事件筛选与详情、通知范围、外观／时间／账号设置、管理员账号列表及编辑弹层；事件详情截图前置，检测结果按需展开。 |

最终打开真实组件的交互预览，预览连接本机隔离服务与明确标识的模拟临时数据，不交付截图。隔离 Windows 预览启动时保持窗口可见但不主动激活，外观偏好写入隔离账号目录；正常业务启动与偏好路径保持原样。参考生图不替代运行界面；构建、布局计算与实际设备／窗口检查分别记录在[验证记录](90-验证记录.md)。本分支不合并主线、不发布。
