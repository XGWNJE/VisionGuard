# 多平台 UI 组件设计

负责：终端组件尺寸、组合方式与页面布局。不负责：业务逻辑、协议、任务状态与重复验证报告。更新时机：共享组件或页面布局变化时。颜色和图标以[统一规范](70-UI设计规范.md)为准，设备行为仍由各模块负责。设计依据为 owner 提供的 `VisionGuard-0.6-density-preview.pdf`（17 页，2026-10-04），采用 B 精细版“紧凑、不拥挤”。PDF 的示例数据和旧源码判断不作为产品事实。

## 页面组合

### Web 控制台

最小宽度 1040；侧栏 168–184、内容内距 24；五个主入口保持现有权限过滤。节点列表使用横向表格行，列为名称、类型 / 平台、连接、工作状态和详情，选中行用左青色边线。下方是当前节点概况与来源表格，参数检查区位于右侧；较窄桌面自动叠放。设备身份、重命名和解绑放在可展开的设备管理区。

参数使用阅读摘要和逐项编辑；检测目标展开中文搜索多选，英文标签辅助，保留真实模型标签、至少一项、草稿和执行回执规则。事件使用紧凑行与右侧截图详情抽屉，关闭 / Escape / 返回焦点保留。通知范围为主要选择区和离线来源附加区。设置采用两栏表面，账号管理先看列表，创建与编辑在弹层，不让表单长期挤占列表。

### Windows 视觉节点

真实 WPF 主窗保留预览区、可拖动检查区与来源容量。预览卡标题、当前来源编号、状态和启停按钮在同一工作对象附近；画面保持原始比例，未配置只显示真实提示。全局来源仍原位切换，选择只影响预览。检查区用紧凑标题、行分隔和阅读参数；全局设置复用同一字段、按钮、表面资源。

窗口选择、采集选区和遮罩仍为专用工具窗口，工具条采用统一尺寸；托盘、启动器错误和确认提示复用现有主题。系统窗口边框、文件选择不重绘。不按概念图调整来源容量、采样范围或检测工作流。

### Android 相机与通知节点

可用宽度至少 840dp 且字体缩放不超过 1.3 时采用双栏，间距 16dp；其余单列滚动。平板限制内容最大宽度 1200dp；登录表单最大 480dp 居中。系统栏、安全区和键盘遵循平台。

相机优先呈现预览与启停；目标视觉节点为单选，详细候选在弹层；预览收起时停止动作仍可达。平板左预览、右目标与规格 / 亮度 / 隐藏设置。通知平板左接警与声音策略、右最近记录；手机依次呈现。历史、铃声库、录音 / 导入、重命名 / 删除确认复用返回标题、列表行、空状态和弹窗。共用账号、改名、改密与外观入口遵循同一尺寸。

冻结维护的旧 Android 控制台不重新设计页面，仅随共享字体、形状和登录组件收敛；PDF 明确排除手机 Web 和旧 Android 控制台产品扩展。
