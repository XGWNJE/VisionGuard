# 多平台 UI 组件设计

负责：终端组件尺寸、组合方式与页面布局。不负责：业务逻辑、协议、任务状态与重复验证报告。更新时机：共享组件或页面布局变化时。颜色和图标以[统一规范](70-UI设计规范.md)为准，设备行为仍由各模块负责。采用 owner 选定的第 2 套“画面优先”方向：沿用中性灰与青色主题，以频率和重要程度组织内容，拉开关键状态、主操作与辅助信息层次；示意图不作为业务事实。

## 页面组合

### Web 控制台

按 owner 本轮授权采用简洁、有序、紧凑、扁平的工具型布局，保留中性灰 / 青色和同版本 Lucide。桌面侧导航 144–164px、节点目录默认 208–240px（各断点默认值），与工作区并列；节点目录宽度可拖拽（208–480px，双击复位，宽度记在本机浏览器，单列窄视口不显示分隔条）；主导航移除顶部品牌标题、底部账号快捷入口及重复标题，保留功能菜单与原有账号权限；不足 1040px 时侧导航缩为 72px。竖屏与窄视口使用底部导航、目录 / 详情切换和返回全部节点。以实际 CSS 视口适配 8.8 寸平板；桌面控件至少 36px，触屏及窄视口至少 48px，保留安全区和键盘空间。

节点目录、详情与各工作区分别滚动，窄屏保留返回和底部导航安全区。节点顶部显示身份、控制对象和能力允许的操作；工作区为概览、来源、节点设置、诊断与回执。概览保留最近事件及推流/接收上下文；来源列表与详情在宽屏并排，窄屏顺序排列。逐来源规则只在来源详情编辑，节点设置集中账号设备关联、远程配置和缓存，诊断显示组件与执行回执。标签自然宽度、可横向滚动；缺值标明未报告，历史画面不冒充实时。详细职责见[控制台](50-控制台与通知节点.md)。

参数采用阅读行与逐项编辑，草稿跨分类保留，切对象或主工作区前可保存、放弃或继续编辑；保存并离开等待执行端 completed 回执，失败停留。模型、阈值、冷却、FPS 与目标沿用现有契约。标签支持方向键 / Home / End 移动焦点、Enter / Space 切换。

事件使用带筛选的紧凑行与右侧截图抽屉，保留关闭 / Escape / 返回焦点。事件列表独立滚动，筛选区保留在上方；筛选区超过可用高度时也可局部滚动。搜索、类型与起止时间共同筛选已加载的最近最多 100 条事件；时间按账号的北京时间或 UTC 解释，允许只填一端，结束时间包含该秒，起止倒置时提示错误。清除时间不影响搜索 / 类型；退出账号或切换时间标准清空时间条件。通知范围采用通知节点目录与独立编辑区，两区分别滚动，切换节点保留草稿，范围选择与保存操作在编辑区滚动时保持可见，离线来源在辅助展开区。设置页左侧账号与本机，右侧常规设置（外观 / 统一时间）与缓存；沿用节点 / 事件 / 通知范围页的全宽内容与页边距，采用等宽双列和对齐的字段 / 操作列，每个设置面板独立滚动；内容宽度不超过 1040px 使用账号与本机 / 常规设置 / 缓存分区切换，保留未提交的字段草稿，560px 内标签移到字段上方。操作列统一 112px，密码框与名称框左侧对齐，保留必要提示；外观选择沿用主按钮的青色选中样式。账号管理先看列表，创建和管理使用弹层。登录页采用居中的紧凑表单，仅保留文字品牌、登录标题、账号密码、记忆选项与登录操作；删除宣传语、功能介绍和重复说明，暂不放品牌图形及功能图标，错误按需显示。外观保留跟随系统 / 浅色 / 深色分段选择，登录页使用纯文字选项，选择器与表单共用面板底色和细边框，选中项使用主按钮的青色填充。所有页面保留空态、错误、禁用原因和危险操作确认。

### Windows 视觉推理节点

WPF 保留主预览、紧凑来源列表和检查区。列表只显示名称、状态、帧率，完整信息进入来源详情的概览、采集与来源、检测规则、遮罩。规则与遮罩编辑独立草稿并提供离开保护；来源配置成功才入列、临时断流保留配置，画面等比留边。默认 1420×800 DIP、最小 720×480 DIP；两根分隔条分别调节来源与检查区，不足 1080 DIP 时检查区使用侧层，内容独立滚动。

全局设置按账号与设备、模型资源、外观、后台运行、版本与维护、运行方式、节点状态组织。节点级模式及绑定影响全部来源，独立于选中的来源；模型下载只有全局入口，来源规则提供跳转。长文字换行或显示完整提示，不强制一屏装完。现有容量、采样范围与检测链不变，详情见[Windows 节点](30-Windows视觉节点.md)。

### Android 视觉推理、相机与通知节点

Android 推理端主工作区保留预览、来源与关键异常；来源详情按概览、采集与来源、检测规则、遮罩组织，宽屏来源目录与详情并排、窄屏完整详情。规则用紧凑有界输入，遮罩宽屏画布与列表并排；不预设六页或固定高度。设置目录将节点状态与账号设备、模型资源、外观、后台权限、维护分开。草稿与离开保护、模型资源职责见[Android 节点界面](31-Android视觉推理节点.md#界面)。

相机主页面仅有控制 / 状态与预览两个区域：手机控制区占一半，平板占三分之一（可用短边至少 600dp，字号不超过 1.3），大字号控制区占一半。横屏左控制右预览，竖屏上预览下控制，区域间距 12dp；关闭预览只在原区域居中显示状态，尺寸和位置不变。正常场景主控件一屏容纳，极短窗口或超大字号保留控制区内滚动与固定启停。通知主页面为接警控制 / 最近报警双区：横屏左控制右记录，竖屏上控制下记录，手机各占一半，平板控制占三分之一（可用短边至少 600dp）；内距与区域间距均为 12dp。常规字号两区各自滚动，接警按钮固定在控制区底部；字号超过 1.3 或竖屏可用高度不足 440dp 时改为单列整页滚动。登录表单最大 480dp 居中，系统栏、安全区和键盘遵循平台。

相机控制区包含账号 / 帮助 / 设置的同尺寸图标入口、独立状态行、入队 / 服务收帧 / 两端丢弃三列统计、共用标签列的目标与规格、等宽规格按钮、等宽亮度 / 预览开关及底部固定启停。主控件触点至少 48dp，行间距统一按高度为 4dp / 12dp，宽松高度下控制组居中；预览开关采用开启语义。解释、完整状态 / 统计 / 来源、采集尺寸与主动未采样计数统一放帮助页；主界面保留实际发送尺寸 / 回退，不堆叠操作提示。预览区只呈现画面或居中状态。

通知顶部同样提供账号 / 帮助 / 设置 48dp 图标入口。两区标题最小高 48dp、水平内距 12dp，标题与状态 / 全部记录共用中心线；控制内容从顶部排列，接收范围与铃声的标签列为随字号缩放的 64dp，字段值和箭头各自对齐。常规控件间距 8dp、水平内距及按钮底部留白 12dp；控制区高度不足 320dp 时，内容间距缩至 4dp、按钮底部留白为 8dp，本次收件 / 服务响应移至帮助，保留 48dp 触点。控制区集中连接状态、重连、系统通知缺权限入口、接收范围、铃声、等宽循环次数 / 铃声库及接警启停；完整范围、连接地址、时间标准、连接统计和收件 / 播放说明在帮助弹窗中查看。最近报警默认最多六条，列表上下内距 4dp、记录上下内距 8dp，显示来源、时间与实际结束方式，并保留全部记录入口；大字号单列显示最近四条。历史、铃声库、录音 / 导入、重命名 / 删除确认复用返回标题、列表行、空状态和弹窗。共用账号、改名、改密与外观入口遵循同一尺寸。

通知告警确认用全屏目标展示：竖屏居中目标名称与位图，宽横屏左图右名称，系统安全区内距 24dp，超大字号保留内容滚动。人 / 汽车的透明 PNG 位于 `notifier/android/app/src/main/res/drawable-nodpi/`，由 imagegen 生成并保留原像素，作为目标示意而非事件画面；功能入口继续使用 Lucide。目标名称为主要文本，短名称 64sp，其他类别与连接中断等事件使用可换行标题。图像柔和浮现 420ms、扫描光带周期 3600ms，系统关闭动画时静态显示。全屏展示区轻点即可调用确认停止，底部仅提示操作；48dp 详情入口消费自身点击，不确认告警。详情另开普通弹窗，关闭返回未确认告警；确认错误始终可见，不替代保存结果。
