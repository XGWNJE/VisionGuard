# 多平台 UI 组件设计

负责：终端组件尺寸、组合方式与页面布局。不负责：业务逻辑、协议、任务状态与重复验证报告。更新时机：共享组件或页面布局变化时。颜色和图标以[统一规范](70-UI设计规范.md)为准，设备行为仍由各模块负责。采用 owner 选定的第 2 套“画面优先”方向：沿用中性灰与青色主题，以频率和重要程度组织内容，拉开关键状态、主操作与辅助信息层次；示意图不作为业务事实。

## 页面组合

### Web 控制台

优先保障 8.8 寸平板。横屏使用侧导航，节点列表 200–280px 与详情并排；不足 1040px 时侧导航缩为 80px。竖屏及窄视口使用底部导航，节点列表与详情独立切换，详情保留返回全部节点。触点至少 48px，安全区与键盘保留，来源表格局部滚动。详情依次呈现节点状态与启停、最近事件画面、来源、参数、设备管理和回执；历史事件截图明确标记，不冒充实时视频。

参数使用阅读摘要和逐项编辑；检测目标展开中文搜索多选，英文标签辅助，保留真实模型标签、至少一项、草稿和执行回执规则。事件使用紧凑行与右侧截图详情抽屉，关闭 / Escape / 返回焦点保留。通知范围为主要选择区和离线来源附加区。设置采用两栏表面，账号管理先看列表，创建与编辑在弹层，不让表单长期挤占列表。

### Windows 视觉节点

真实 WPF 主窗按参考图组织为简洁顶栏、左侧大主画面、右侧最多三路纵向辅助画面、底部常驻来源缩略列表和可拖动检查区。选择预览来源同步切换主画面与检查对象；检查非预览来源保留主画面，检查区明确提示。勾选只决定预览成员，不改变采集与推理，全局来源同样分开查看与勾选。最多四路实时预览，其他来源继续推理。卡片名称、状态与 FPS 覆盖在画面上沿，主画面显示有界检测标签，辅助画面保留检测框；底部只显示当前可用的启动或停止及更多菜单；未配置使用真实空态，停止后的保留画面明确标识。

最小 1040×540 DIP，默认 1420×800 DIP，启动尺寸受工作区约束；1600×900 下按 DPI 折算检查。主卡片至少宽 320 DIP、画面区高 240 DIP，辅助卡片至少宽 240 DIP、高 120 DIP；紧凑工作区使用局部滚动，保留 36 DIP 操作与原始画面比例。检查区前置采集摘要及选择窗口／选区／遮罩，检测参数默认只显示摘要和独立编辑窗口入口，辅助来源信息折叠。编辑窗口常用选项同屏呈现，展开内容局部滚动，取消、还原与保存固定在底部。置信度保留 10–95% 的 1% 滑块与细调；采样使用 1–5 FPS 按钮选项，冷却使用 5／10／30／60 秒档位及完整 1–300 秒选择。全局设置复用同一字段、按钮、表面资源。组件实现与实机覆盖边界分别维护，实际检查结果只见[验证记录](90-验证记录.md)。

窗口选择、采集选区和遮罩仍为专用工具窗口，工具条采用统一尺寸；托盘、启动器错误和确认提示复用现有主题。系统窗口边框、文件选择不重绘。不按概念图调整来源容量、采样范围或检测工作流。

### Android 相机与通知节点

可用宽度至少 840dp，或横屏宽度至少 480dp，且字体缩放不超过 1.3 时采用双栏，间距 16dp；其余单列滚动。平板限制内容最大宽度 1200dp；登录表单最大 480dp 居中。系统栏、安全区和键盘遵循平台。

相机优先呈现预览与启停；目标视觉节点为单选，详细候选在弹层；预览收起时停止动作仍可达。横屏左侧预览权重 1.5、右侧目标与规格／亮度／隐藏设置，预览高度根据可用屏高约束；640×480 与 720P 使用档位选择。通知主栏放接警和最近记录，次栏放可展开声音策略与权限入口；竖屏按此顺序阅读。统计、连接详情和声音详细配置按需展开。历史、铃声库、录音 / 导入、重命名 / 删除确认复用返回标题、列表行、空状态和弹窗。共用账号、改名、改密与外观入口遵循同一尺寸。

旧 Android 控制台保留任务与导航，随共享字体、形状、登录和账号条收敛；既有参数使用选项和有界滑块，冷却支持 1–300 秒与逐秒细调。

## 交付与边界

界面覆盖范围（系统文件选择、权限页及安装器继续使用平台控件）：

| 组件 | 页面与控件 |
|---|---|
| 共享 Android | 登录、账号菜单、改名／改密、外观选择、更新进度／取消／安装确认；小屏弹窗正文滚动，主按钮保持可达。 |
| 相机推流节点 | 画面、启停、目标列表、规格档位、亮度／隐藏开关、统计与权限反馈。 |
| 通知节点 | 接警面板、范围摘要、连接详情、历史与清空确认、报警确认、声音／次数选择、铃声库、导入／录音、重命名／删除与权限说明。 |
| Web 控制台 | 登录、节点筛选／详情／来源／参数／设备管理／回执、事件筛选与详情、通知范围、外观／时间／账号设置、管理员账号列表及编辑弹层；事件详情截图前置，检测结果按需展开。 |
| Windows 视觉节点 | 预览卡、来源管理、参数、全局设置、模型资源、采集窗口／选区／遮罩工具、托盘与启动器提示。 |
| Android 控制台 | 设备及来源、参数调节、事件列表／详情、账号与连接反馈；冷却保留完整范围与逐秒调整。 |

最终打开真实组件的交互预览，预览连接本机隔离服务与明确标识的模拟临时数据，不交付截图。隔离 Windows 预览启动时保持窗口可见但不主动激活，外观偏好写入隔离账号目录；正常业务启动与偏好路径保持原样。参考生图不替代运行界面；构建、布局计算与实际设备／窗口检查分别记录在[验证记录](90-验证记录.md)。本分支不合并主线、不发布。
