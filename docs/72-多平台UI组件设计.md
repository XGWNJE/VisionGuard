# 多平台 UI 组件设计

负责：终端组件尺寸、组合方式与页面布局。不负责：业务逻辑、协议、任务状态与重复验证报告。更新时机：共享组件或页面布局变化时。颜色和图标以[统一规范](70-UI设计规范.md)为准，设备行为仍由各模块负责。采用 owner 选定的第 2 套“画面优先”方向：沿用中性灰与青色主题，以频率和重要程度组织内容，拉开关键状态、主操作与辅助信息层次；示意图不作为业务事实。

## 页面组合

### Web 控制台

按 owner 本轮授权采用简洁、有序、紧凑、扁平的工具型布局，保留中性灰 / 青色和同版本 Lucide。桌面侧导航 144–164px、节点目录 208–240px，与工作区并列；不足 1040px 时侧导航缩为 72px。竖屏与窄视口使用底部导航、目录 / 详情切换和返回全部节点。以实际 CSS 视口适配 8.8 寸平板；桌面控件至少 36px，触屏及窄视口至少 48px，保留安全区和键盘空间。

节点工作区顶部直接呈现身份、连接 / 工作状态、控制对象和能力允许的启停、报警确认、应用操作；下方使用运行与事件、参数与配置、设备管理、操作回执四个标签页。运行区在宽桌面并列展示来源与最近历史截图，较窄视口改为纵向；桌面来源表格局部滚动，窄屏来源改为紧凑行，名称、状态、实际帧率与启停 / 参数操作一起显示。相机运行区呈现推流关联，通知节点提供接收范围及编辑入口；未报告内容明确标注。历史事件画面不能冒充实时视频。

参数使用阅读行与逐项编辑，来源入口直接定位当前来源配置；模型、滑块、冷却预设、FPS 档位及中文目标多选沿用现有契约。工作区切换保留草稿，控制对象明确展示，保存以执行回执为准。标签支持方向键 / Home / End 移动焦点、Enter / Space 切换。

事件使用带筛选的紧凑行与右侧截图抽屉，保留关闭 / Escape / 返回焦点。通知范围采用通知节点目录与独立编辑区，切换节点保留草稿，范围选择旁提供保存，离线来源在辅助展开区。设置采用账号与本机、外观、统一时间、缓存四个分区；账号管理先看列表，创建和管理使用弹层。登录采用品牌介绍与简短表单，窄屏收为单列；外观使用跟随系统 / 浅色 / 深色分段选择。所有页面保留空态、错误、禁用原因和危险操作确认。

### Windows 视觉节点

真实 WPF 主窗为左侧主预览、中间全部有效来源的纵向卡片、右侧来源检查；移除应用内品牌／连接顶栏、底部来源条和预览勾选。点击来源同步主画面与检查对象，所有来源保留在中间列表。配置草稿先选择窗口或屏幕区域，成功后才入列；取消或失败销毁草稿。已配置来源暂时断流不销毁。无来源显示添加入口，远程绑定由同步消息自动入列。列表虚拟化与可见范围判断只减少位图刷新，不改变推理或报警。主画面保留有界检测标签，列表卡片只保留检测框；画面等比、不裁切，停止保留最后画面并明确标识。

默认 1420×800 DIP、最小 720×480 DIP，按实际工作区适配；900P 是检查场景，不是固定排版标准。来源列宽 240–380 DIP、检查区宽 300–420 DIP；两根分隔条独立调节侧栏，拖动过程就限制边界，主画面获得剩余空间；不足 1080 DIP 时检查区作为侧层展开，列表和检查内容分别滚动。来源卡片按画面比例计算高度并限制在 156–420 DIP，极端比例在卡片内留边。来源检查依次为当前来源、运行状态与启停、常用检测规则、采集范围与遮罩、来源管理；实际帧率、后端、推理耗时和最后报警属于运行状态，直接显示不折叠，目标帧率、置信度和报警冷却属于规则；同组字段基准行高 32 DIP，单操作按钮占所在列宽，采集窗口／选区为等宽双按钮；按来源类型显示合法操作，不留下空配置重置入口。更换目标失败回退，参数整组编辑继续使用独立草稿、取消／还原／保存及运行中只读规则。

来源卡片内层以圆角裁切，外层描边覆盖画面与标题。列表、检查区与全局内容页统一滚动留白：视口至轨道 12 DIP、轨道宽 10 DIP、距分区外沿 8 DIP，滚动条隐藏时保留槽位；全局正文沿用最大 800 DIP 的阅读宽度。

全局设置覆盖当前窗口内容区，左侧五类导航，右侧独立内容：账号与连接、推理与模型、外观、后台运行、版本与维护。登录后隐藏登录输入，维护操作与日常设置分开；返回保留预览选中来源和列表位置。两个区域共用菜单资源：同级控件高 36 DIP、内距 12／4，分组间距 24、字段间距 12、成组间距 8；检查参数标签列 72 DIP，全局标签列 96 DIP、操作列 112 DIP，按钮宽度由所属列决定。长文字使用换行、完整提示或局部滚动，不任意改变控件尺寸。外观三选项等宽，选中状态可见；采样 1–5 FPS、冷却 1–300 秒、置信度 10–95% 的既有边界保留。

窗口选择、采集选区和遮罩仍为专用工具窗口，工具条采用统一尺寸；托盘、启动器错误和确认提示复用现有主题。系统窗口边框、文件选择不重绘。不按概念图调整来源容量、采样范围或检测工作流。

### Android 相机与通知节点

相机主页面仅有控制 / 状态与预览两个区域：手机控制区占一半，平板占三分之一（可用短边至少 600dp，字号不超过 1.3），大字号控制区占一半。横屏左控制右预览，竖屏上预览下控制，区域间距 12dp；关闭预览只在原区域居中显示状态，尺寸和位置不变。正常场景主控件一屏容纳，极短窗口或超大字号保留控制区内滚动与固定启停。通知节点仍在可用宽度至少 840dp，或横屏宽度至少 480dp，且字号不超过 1.3 时采用双栏，内容最大宽度 1200dp；其余单列滚动，间距 16dp。登录表单最大 480dp 居中，系统栏、安全区和键盘遵循平台。

相机控制区包含账号 / 帮助 / 设置、状态、关键入队 / 服务收帧 / 两端丢弃统计、目标单选、规格、亮度、预览及启停；两个开关并排，预览开关采用开启语义。解释、完整状态 / 来源与主动未采样计数统一放帮助页；正常主界面不堆叠操作提示。预览区只呈现画面或居中状态。通知主栏放接警和最近记录，次栏放可展开声音策略与权限入口，竖屏按此顺序阅读；统计、连接详情和声音详细配置按需展开。历史、铃声库、录音 / 导入、重命名 / 删除确认复用返回标题、列表行、空状态和弹窗。共用账号、改名、改密与外观入口遵循同一尺寸。

最终打开真实组件的交互预览，预览连接本机隔离服务与明确标识的模拟临时数据，不交付截图。隔离 Windows 预览启动时保持窗口可见但不主动激活，外观偏好写入隔离账号目录；正常业务启动与偏好路径保持原样。参考生图不替代运行界面；构建、布局计算与实际设备／窗口检查分别记录在[验证记录](90-验证记录.md)。本分支不合并主线、不发布。
