# VisionGuard v4.5.0

本版本是检测端界面与性能反馈的一次大改，并提升服务端来源上限；Android 检测端本次不随版本发布。

## 主要变更

- **检测端界面重构**：右侧控制台合并为「当前来源 / 全局设定」两页；来源卡片改为自适应布局，卡片接近方形、卡片内画面区不小于 320×320。
- **实时预览位**：最多 4 路同时预览；其余来源照常采集、推理与报警，只是不占预览画面，分页翻页已取消。
- **全局来源视图**：用编号卡片一屏看全所有来源，点选要进入实时预览的那几路。
- **性能提示改按实测帧率**：实测低于该路目标帧率 80% 且持续 30 秒才提醒（卡片提示 + 弹窗，弹窗冷却 10 分钟），不再需要手动配置容量基线。
- **模型下载**：按推理档位列出并支持行内下载，失败原因直接显示在对应模型行上。
- **服务端**：每台探测器的来源上限默认提升到 16 路并在认证/心跳中下发，超限会明确告知设备与接收端。
- **修复**：Windows 7 上重复启动即崩、按档位解析模型输出导致的漏检；未处理异常现在会写入本地崩溃日志。

## 升级提示

- Windows 7 SP1 请使用 `VisionGuard-WPF-Legacy-*` 包；Windows 10/11 使用 `VisionGuard-WPF-*` 包，两者原生推理库不通用。
- 服务端来源上限可用 `MAX_SOURCES_PER_DETECTOR` 调整（范围 1–16）。

发行包仍不包含 ONNX 模型；客户端按需从 VisionGuard Server 下载模型。
