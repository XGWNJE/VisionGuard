# VisionGuard v4.5.1

本版本修复 Windows 检测端在极端比例来源与退出场景中的稳定性问题；Android 两端随统一版本号发布。

## 主要变更

- **等比画面**：来源卡片预览和模型输入统一使用等比缩放、居中黑边填充，不拉伸画面；极端选区不会再挤压卡片操作区。
- **识别提示**：选区长宽比超过 2:1 时，显示有效画面占比提示，说明 1:1 是最佳输入比例。
- **稳定性修复**：修复无来源画面启动时的布局异常，以及退出期间托盘双击可能触发的未处理异常。
- **完整退出**：新增一次性关闭检测端主体与驻留程序的入口，同时移除驻留自启动。
- **界面整理**：全局设定中的“模型资源”默认折叠。

## 升级提示

- Windows 7 SP1 请使用 `VisionGuard-WPF-Legacy-*` 包；Windows 10/11 使用 `VisionGuard-WPF-*` 包。
- 发行包仍不包含 ONNX 模型；客户端按需从 VisionGuard Server 下载模型。
