# 0.6.4 内测版

负责：本版发行内容、安装方式与已知覆盖边界。不负责：任务进度或重复验证记录。更新时机：本版发布前核对最终内容；发布后只纠正历史事实。

- 修复相机首次授权后没有画面：保留本次用户点击的启动请求，授权成功且页面回到前台后启动采集；拒绝授权或真正离开页面则取消请求。
- 只有正在推流时才因离开前台停止，不再把相机授权弹窗误显示成“离开前台，推流已停止”。真正切到后台仍立即停流，返回后须手动开始。
- 包含 0.6.3 的账号限流与 Windows 告警修复，避免同网络下正常组件互相耗尽 API 请求额度，影响目标视觉节点加载。

发行范围为 Windows 整包、Android 相机推流节点和通知节点两个签名包，以及统一服务／Web；旧 Android 控制台发行保持 0.6.0。通知节点本轮只同步版本。Android 使用同签名包覆盖安装；Windows 完整解压后运行根目录 `VisionGuard.Detector.Windows.exe`。

小米 15 尚未连接调试，是否覆盖其现场故障须安装本版后实测。真机、服务器隔离链路和发行校验结果统一见[验证记录](../90-验证记录.md)，推流成功不等于完整通知收件与声音报警通过。
