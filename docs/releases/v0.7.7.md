# VisionGuard v0.7.7

负责：本版发行范围与升级说明。不负责：完整验证报告。更新时机：本版内容变化时。证据见[验证记录](../90-验证记录.md)。

## 本版内容

- 通知节点：原生界面统一为控制台 Neutral 浅深色，整理接警工作台、报警记录、声音与音频、设置四页；手机 20:9 与平板 16:10 分别布局。
- 报警确认：改为信息优先的全屏页，仅底部按钮确认当前报警，保留排队数量、失败重试、自动推进与原页面状态；移除大幅示意图和扫描动效。
- 更新与状态：保留登录页和设置中的 GitHub 稳定版更新入口，修正本地服务更新源恢复及启动检查顺序、最后响应时间显示，以及 Android 安装辅助脚本的设备选择、时区校验和英文更新按钮识别。

## 升级说明

发布 Windows 统一包、Android 相机推流节点／通知节点／视觉推理节点，以及统一服务与两端 Web。客户端可在应用内检查更新并按系统提示确认安装，也可手动安装对应发行包。

协议版本为 **0.7.7**；服务升级后旧版本节点需要同步更新，Web 页面刷新后生效。
