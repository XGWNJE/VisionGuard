# VisionGuard v0.7.0

负责：本版发行范围和安装说明。不负责：完整验证报告。更新时机：本版发行内容变化时。

## 本版内容

- **模型档位收敛为三端四档**，用户不再需要在长列表里挑选：视觉推理节点 legacy 档（Win7）只保留 `yolov5su_320` 与 `yolov5mu_320`；modern 档固定 `yolo26m_320` 与 `yolo26m_640`；Android 推理节点只保留 **GPU 档** `yolo26m_320` / `yolo26m_640`（只下载截断图 `_gpu.tflite`）与 **CPU 档** `yolo26m_320_int8` / `yolo26m_640_int8`（只下载量化版本体）。CPU 不再跑 FP32，性能不足时用 320 档。
- **后端随档位绑定**：选中 GPU 档即走 LiteRT GPU，CPU 档走 ONNX Runtime CPU；设备没有可用的 GPU 加速器时 GPU 档不可选、来源配置自动落到同尺寸 CPU 档；GPU 加载失败也在运行期回落到同尺寸 INT8 并写明原因。
- **320 档 GPU 产物首次上架**：新造 `yolo26m_320_gpu.tflite`（截断图 + FP32），真机实测 26.2 ms 对同运行时 CPU 基线 63.4 ms（**0.41×，达标**），质量与正式模型一致。
- **Android 模型管理并入参数抽屉**：下载、删除与选择都在「来源 → 参数 → 模型插槽」，未下载的档位不可选中、使用中的档位不可删除；「全局设置 → 模型」只留推理状态与只读概览；升级后本机自动清理清单外的旧档位文件。
- **多路上限按新清单重测**：320 INT8 4 路、640 INT8 2 路（单路 ≥5 帧/秒 为界），两个 GPU 档 32 路未触底；超限时新增来源被拒并给出可读原因。
- **视觉推理节点支持应用内更新**：「设置 → 维护 → 检查更新」可直接下载并交给系统安装器（走 GitHub 稳定发行，做 sha256、包名、版本与签名校验）。本版起 GitHub 发行包含推理节点安装包，此前只能手动安装。
- 服务端模型目录同步收敛：保留 8 个文件，下架 12 个旧档位文件（约 273 MiB）。
- 发布 Windows 视觉推理节点、Android 相机推流节点、通知节点、视觉推理节点，以及统一服务 / Web；Android 控制台继续退役，历史 0.6.0 下载元数据保留。

## 安装与检查

更新各客户端并刷新[线上控制台](https://visionguard.xgwnje.cn/console/)。各端「关于 / 版本」当前应为 0.7.0。

- **Android 视觉推理节点**：可以在应用内「设置 → 维护 → 检查更新」升级；本版起 GitHub 发行含 `VisionGuard-Inference-v0.7.0.apk`。
- **档位变化**：升级后 n / s 档位不再出现在选择列表（已下载的旧文件会在启动时清理），默认档为 `YOLO26M · 320 CPU`；要 GPU 加速请下载 `M·320 GPU` 或 `M·640 GPU`（GPU 档需要同尺寸 CPU 档在位作为回落）。
- **Windows 视觉推理节点**：modern 档设置页只剩 `YOLO26m 320` / `YOLO26m 640`，legacy 档只剩 `YOLOv5su 320` / `YOLOv5mu 320`。

构建、发行附件与真机证据见[验证记录](../90-验证记录.md)。
