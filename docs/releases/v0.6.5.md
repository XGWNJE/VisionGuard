# VisionGuard v0.6.5

负责：本版发行范围和安装说明。不负责：完整验证报告。更新时机：本版发行内容变化时。

## 修复内容

- 修复正式服务器反向代理遗漏 `/media/ws` 升级规则的问题：控制连接和绑定能成功，媒体却返回 HTTP 404，导致所有采集帧在本机被丢弃、没有预览。正式配置与仓库模板同时修复；该服务器修复也适用于 0.6.4 客户端。
- 发布流程新增控制与媒体入口的独立 WebSocket 握手检查，任何一路失败都阻止公开发行，并保留草稿。检查无需登录，不发送业务帧。
- 客户端功能沿用 0.6.4；发行范围为 Windows 视觉节点、Android 相机与通知节点及统一服务／Web。旧 Android 控制台保留 0.6.0。

## 实装检查

小米 15 更新后在前台开始推流，确认预览出现、本机入队和服务收帧增长；手动停止后计数停止，重新开始后恢复增长。公网握手成功不等于小米 15 画面与完整报警链已通过，实际覆盖见[验证报告](../90-验证记录.md)。
