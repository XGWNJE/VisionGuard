# VisionGuard v0.6.10

负责：本版发行范围和安装说明。不负责：完整验证报告。更新时机：本版发行内容变化时。

## 本版内容

- 修复 Android 检查更新时重复下载的问题：重新查询稳定发行，核对实际安装版本；当前已是最新版本时停止下载，有效的已有安装包恢复为可安装状态。相机与通知节点共用此逻辑。
- 通知节点主页面采用紧凑双区布局，统一间距、对齐和留白；接警、通知范围、铃声与最近报警更容易操作，连接统计收进帮助。
- 告警确认界面突出发现的对象，以人 / 汽车位图配合柔和浮现、光晕与扫描光带表达检测结果。多个目标只展示合法置信度最高的一个；不显示“目标示意”文字，来源、时间、摘要及置信度收进详情。
- 图像、文字和空白均可轻点确认停止报警，详情入口独立；目标随报警队列保存，重建与重复回执保持一致。其他类别及中断告警保留真实名称。
- 本版发行 Windows 视觉节点、Android 相机与通知节点，以及统一服务 / Web；旧 Android 控制台继续退役，历史 0.6.0 下载元数据保留。工程文档、任务入口及发布授权保护同步整理。

## 安装与检查

从本版发行页更新三个客户端；Web 刷新[线上控制台](https://visionguard.xgwnje.cn/console/)。通知节点检查更新应显示已是最新版本；实际检测人或汽车时，检查对象表达、详情入口及大面积确认停止。

本版不包含通知节点锁屏收件问题修复。位图表达对象类别，实际检测画面与完整事件信息由控制台查看。构建、附件及公网检查的覆盖边界见[验证记录](../90-验证记录.md)；真实完整报警链、可听声音与长时运行由 owner 单独验收。
