# VisionGuard v0.6.12

负责：本版发行范围和安装说明。不负责：完整验证报告。更新时机：本版发行内容变化时。

## 本版内容

- 视觉推理节点接入发布流水线：平台表新增 `android-inference`，产出 `VisionGuard-Inference-v0.6.12.apk` 并写入更新元数据（`/api/update?platform=android-inference`）。端侧的「检查更新 → 下载安装」入口尚未实现，本版先具备可下载的发行资产与元数据。
- 推理加速落地：正式档为 ONNX Runtime · CPU 4 线程，加速档为 LiteRT GPU + 截断图，按“有 GPU 产物且已下载”自动启用，用不了显式回落 CPU 并说明原因。模型清单 12 项（本体 + 量化），每项在设置里直接标出跑在哪（`GPU` / `CPU` / `CPU · INT8`）。真机实测：640 单路 GPU 67.0 ms、帧率 3.0 与解析 0.9–1.8 ms。
- 多路限制按“模型 + 后端”生效（CPU 32/4/2 路、GPU 32 路），新增来源与服务端下发的流都同一道关；心跳上报推理后端与并发上限，控制台据此解释为什么加不了更多来源。
- 修掉视觉推理节点 release 包启动即崩：CameraX 带入的 WorkManager / Room 靠反射取类名，被 R8 收缩后进程在 ContentProvider 阶段就挂（此前只有调试包上过真机）。
- 模型分发：服务端投放 12 个 ONNX（6 个本体 + 6 个量化）与 1 个 GPU 截断图产物；端侧按需下载。
- 发布 Windows 视觉推理节点、Android 相机推流节点、通知节点、视觉推理节点，以及统一服务 / Web；Android 控制台继续退役，历史 0.6.0 下载元数据保留。

## 安装与检查

更新各客户端并刷新[线上控制台](https://visionguard.xgwnje.cn/console/)。Android 各节点的设置与更新弹窗当前版本应为 0.6.12。

视觉推理节点本版起可从 `https://visionguard.xgwnje.cn/releases/VisionGuard-Inference-v0.6.12.apk` 下载，但应用内还没有更新入口，需手动安装；GPU 加速在“全局设置 → 模型资源”下载 `YOLO26M · 640` 的 GPU 产物后自动启用。构建、发行附件与真机证据见[验证记录](../90-验证记录.md)。
