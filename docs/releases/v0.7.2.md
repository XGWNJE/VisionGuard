# VisionGuard v0.7.2

负责：本版发行范围和安装说明。不负责：完整验证报告。更新时机：本版发行内容变化时。

## 本版内容

- **Windows 视觉推理节点新增推流态**：本机推理与推流到其他推理节点是两种互斥状态，界面顶部直接切换。推流态只采集并推送画面，不加载模型、不做检测、不产生本机报警。
- **推流目标可在本机选**：推流态的「推流目标」下拉列出同账号的推理节点（含在线状态），选中即绑定，重开应用仍保留；也可以继续由控制台关联。推流端本机预览保留（复用同一份采集画面、不带检测框），运行状态区按推流口径显示（推流帧率 / 已确认帧 / 丢弃帧），服务端拒收原因（未绑定目标、目标未接入媒体通道）直接显示在状态行。
- **服务端媒体中继按能力放行**：发布侧要求 `video-publish` 能力、订阅侧要求推理能力；同一台设备同一时刻只允许一个方向；相机推流节点仍由绑定自动接入，推理发布端不会被自动绑定。
- **控制台补推流关联、状态与启停**：节点详情能看到推流目标、推流状态并启停推流，状态取值与节点自报的 运行 / 起始 / 错误 / 停止 对齐。
- **本地服务模拟数据改为开关**：`scripts/ui-preview.ps1 -MockData` 才注入场景节点、事件与截图，默认关闭；停止模拟数据时同时解绑自己的模拟节点，不影响其它流程。
- **发布前置校验 CI**：发布预检把目标提交的 Development checks 作为第一道闸门——非 success（含 cancelled、仍在跑）或提交还没推上去都会中止发布，避免再出现 CI 红着发版。
- **修复**：`AccountMedia.Probe` 的报警发件箱断言由固定 200 ms 等待改为有界等待，消除跑机调度慢时的偶发误报（受理回执处理晚于夹具收尾被读成丢回执）。
- 发布 Windows 视觉推理节点、Android 相机推流节点、通知节点、视觉推理节点，以及统一服务 / Web。

## 安装与检查

更新各客户端并刷新[线上控制台](https://visionguard.xgwnje.cn/console/)。各端「关于 / 版本」当前应为 0.7.2。

- **Windows 视觉推理节点**：仍是一个统一包，启动器在本机选择内部推理运行时。推流态在「本机状态」里切换，并在「推流目标」里选择接收画面的推理节点。
- **Android 视觉推理节点**：可在应用内「设置 → 维护 → 检查更新」升级；本次发行含 `VisionGuard-Inference-v0.7.2.apk`。
