# VisionGuard v0.6.11

负责：本版发行范围和安装说明。不负责：完整验证报告。更新时机：本版发行内容变化时。

## 本版内容

- 统一使用“视觉推理节点”显示名，同步 Windows 窗口、托盘、应用元数据、跨端文案与新节点默认名称；相机继续显示“相机推流节点”，已有自定义名称保留。
- Web 控制台刷新恢复本标签页会话，默认从登录成功起计 24 小时，到期重新登录；刷新或续期不延长截止时间。不同标签页的会话互不覆盖，退出、撤销与账号失效及时清除。
- 通知节点在默认网络或 VPN 底层网络恢复时取消旧的重连退避，缩短恢复接警的等待；加入连接、收件持久化与队列诊断，便于继续定位锁屏漏收。
- Android 设置页和更新弹窗统一显示系统实际安装版本，修复安装 0.6.10 却显示 0.6.9 的问题；相机与通知节点共用此逻辑。
- 发布 Windows 视觉推理节点、Android 相机推流节点与通知节点，以及统一服务 / Web；旧 Android 控制台继续退役，历史 0.6.0 下载元数据保留。

## 安装与检查

更新三个客户端并刷新[线上控制台](https://visionguard.xgwnje.cn/console/)。旧 Web 会话在本版首次使用时需重新登录；之后有效期内刷新保持登录。Android 设置与更新弹窗的当前版本应为 0.6.11。

小米 15 已完成多轮黑屏锁定、不等间隔（含超过半小时）的收件回执与持久化取证，测试未使用声音作为送达证明；最初锁屏漏收的根因仍未确认，本版不承诺该问题已完全解决。构建、发行附件和运行证据见[验证记录](../90-验证记录.md)。
