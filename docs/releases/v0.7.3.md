# VisionGuard v0.7.3

负责：本版发行范围和安装说明。不负责：完整验证报告。更新时机：本版发行内容变化时。

## 本版内容

- **协议版本闸门收紧为「按本版声明」**：所有端必须声明自己的版本号。版本不是本服务版本的端点会被直接切断（WS 4001 / HTTP 426），并且**不再出现在节点目录与推流视图里**；按本版协议重新声明（升级后重新登录 / 重连）即恢复显示。声明缺失按未声明处理。
- **升级提醒**：本次服务端升级后，**没升级的端会全部失效并从节点目录消失**（这是本版的预期行为，不是故障）。请把四个平台都升到 0.7.3 后再使用；控制台与 Web 相机随服务端一起更新，无需手动升级。
- **Windows 推流节点支持多来源并行推流**：推流态下每个来源各占一条媒体连接与一条流，可以同时把多路画面推给同一个推理节点；接收端按来源分别建卡、各自启停与推理。主动方每多推一个来源，被动方列表就多一个来源。
- **绑定与来源分开，三端都能解除绑定**：绑定是「发布端 → 一个目标推理节点」，发布端还没有来源时也能先绑定；控制台、发布端本机（Windows「解除关联」）、以及被推的被动方（Windows 远程来源、Android 来源抽屉「远程绑定」）都能解除，解掉后该发布端所有来源一起停止推给该目标。
- **修复线上推流链路不通的五处缺陷**：Android 媒体握手不声明版本、首条远程流的引导死锁、看门狗心跳抢在认证之前、Windows 帧头写缩放前尺寸（1080p / 最大化窗口必断）、以及推流态跨线程 GDI+ 互等导致的界面挂死。
- **控制台节点目录可拖宽**：目录与详情之间的分隔条可以拖动（208–480px，方向键微调、双击复位），宽度记在本机浏览器。
- **CI 增加协议声明护栏**：`scripts/check-protocol-declarations.js` 在每次 CI 检查三条通道的闸门、各端的版本声明、推流来源声明、目录可见性与解除绑定权限、版本单一来源，以及「代码里的版本字面量必须由 `scripts/sync-version.js` 收管」。
- 发布 Windows 视觉推理节点、Android 相机推流节点、通知节点、视觉推理节点，以及统一服务 / Web。

## 安装与检查

更新各客户端并刷新[线上控制台](https://visionguard.xgwnje.cn/console/)。各端「关于 / 版本」当前应为 0.7.3。

- **Windows 视觉推理节点**：仍是一个统一包，启动器在本机选择内部推理运行时。推流态在「本机状态」里切换，「推流目标」里选择接收画面的推理节点，每个来源各自「开始推流」，旁边的「解除关联」解掉本节点全部来源的绑定。
- **Android 视觉推理节点**：可在应用内「设置 → 维护 → 检查更新」升级；本次发行含 `VisionGuard-Inference-v0.7.3.apk`。作为被动方时，来源抽屉的「远程绑定」里可以解除某台发布端推给本机的全部来源。
- **升级顺序**：先升级服务端（发布流程自动部署），再升级四个平台的客户端。窗口期内未升级的端会被切断并从节点目录隐藏，属预期。

构建、发行附件与真机证据见[验证记录](../90-验证记录.md)。
