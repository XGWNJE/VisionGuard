# VisionGuard v0.6.8

负责：本版发行范围和安装说明。不负责：完整验证报告。更新时机：本版发行内容变化时。

## 本版内容

- 相机推流节点采用控制 / 状态与预览双区单页布局，按手机、平板及横竖屏匹配比例；关闭预览只替换区域内状态，布局保持稳定。规整顶部入口、统计列、标签列、规格按钮及开关，说明集中到帮助页。
- Web 控制台统一节点、事件、通知与设置工作区的屏高和局部滚动，精简登录页、导航及节点详情；连接和认证分别计时，明确阶段提示，超时重试独立调度。
- Windows 来源列表卡片保持固定 4:3 布局比例，横竖屏画面与检测框居中等比显示，帧方向变化不改变卡片高度。
- 本版发行 Windows 视觉节点、Android 相机与通知节点及统一服务 / Web；旧 Android 控制台继续退役，历史 0.6.0 下载元数据保留。

## 安装与检查

从本版发行页安装客户端，打开[线上控制台](https://visionguard.xgwnje.cn/console/)使用更新后的工作区。相机可切换横竖屏与预览开关检查双区布局。

本版不包含通知节点锁屏收件问题修复。设备 UI、构建、附件与公网检查的覆盖边界见[验证记录](../90-验证记录.md)，不代表完整报警链或长时运行验收。
