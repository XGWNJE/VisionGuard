# VisionGuard v0.6.6

负责：本版发行范围和安装说明。不负责：完整验证报告。更新时机：本版发行内容变化时。

## 本版内容

- 相机推流节点切换横竖屏时保留相机、目标和推流会话，实时更新预览及发送帧的方向，包含系统支持的正反横屏。方向跟随屏幕，不强制绕过系统旋转锁定；切后台或锁屏仍停止推流，返回前台须手动开始。
- 按账号、稳定设备身份与组件复用节点登记，保留自定义名称；默认名称统一为组件类型与设备型号。
- Web 控制台支持相机启停、规格 / 预览 / 变暗配置，通知节点声音策略与音频库管理，以及项目缓存盘点 / 清理；服务与实际节点核对权限、能力、状态并回报执行结果。本机摄像头、解锁与录音等系统授权仍须在设备上完成。
- 发布流程保留上一运行版本的一份完整回滚备份，上线验证成功后回收更早备份及不再引用的产物；截图、安装暂存和诊断缓存具备保留边界，持久账号、配置、模型和在用文件受保护。
- Android 控制台已退出当前产品，统一使用 Web 控制台；历史 0.6.0 安装包元数据保留。本版范围为 Windows 视觉节点、Android 相机与通知节点及统一服务 / Web。

## 实装检查

安装相机新包并开始推流，连续切换竖屏、左横屏、右横屏，确认任务保持、服务收帧持续增长及 Windows 接收画面方向正确；切后台 / 锁屏应停流，返回前台须手动开始。

远程配置和缓存功能须待同版服务 / Web 部署后按[自行验收步骤](../60-构建验证与发布.md#远程配置自行验收)核对。编译、单元检查与发行附件校验不等于真机连续推流、完整报警链、声音或回滚恢复验收，实际覆盖只见[验证报告](../90-验证记录.md)。
