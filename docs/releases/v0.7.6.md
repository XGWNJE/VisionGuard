# VisionGuard v0.7.6

负责：本版发行范围与升级说明。不负责：完整验证报告。更新时机：本版内容变化时。证据见[验证记录](../90-验证记录.md)。

## 本版内容

- 来源管理：修复 Web 绑定后 Android 来源缺失，完整展示未推流来源；同步 Windows 多来源改名与删除，控制台提供来源删除和发布端解绑入口。
- Android 模型：统一为 M320 / M640，每档完整下载两种运行资源后才可选择；程序自动优先兼容的 GPU，失败时回落同尺寸 INT8 CPU。
- 视觉报警：统一 Windows / Android 的负载与时间口径，修复 Android 目标框截图缺失及来源报警时间错误。
- Android 资源：复用并释放 LiteRT 输入 / 输出缓冲，固定来源工作线程，按目标帧率转换相机画面，减少持续分配及界面阻塞。
- Windows 推流：最长边收敛到 960；固定镜头稳定时降低 JPEG 体积，画面变化立即恢复质量，保持采样率。
- Windows 性能：取消性能不足弹窗；设置新增主动采样入口，展示真实各阶段平均 / P95 / 最大耗时及主要瓶颈。
- 设置与配置：三端设置分类、来源与草稿交互整理；Windows 先登录再允许配置来源，避免登录前后配置冲突。
- 发布检查：补齐已发布版本线上巡检、部署退出码保护、当前模型收集范围及 Android Release 编译 / lint CI。

## 升级说明

发布 Windows 视觉推理节点统一包、Android 相机推流节点 / 通知节点 / 视觉推理节点，以及统一服务与两端 Web。安装对应发行包后，刷新[控制台](https://visionguard.xgwnje.cn/console/)；Android 推理来源重新确认 M320 / M640，资源完整后再启动。

协议版本升至 **0.7.6**。服务升级后，旧版本端点会断开并从节点目录隐藏，升级后重新连接；Web 页面需刷新。Android 推理受系统后台限制，持续使用请保持应用前台。
