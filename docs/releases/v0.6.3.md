# 0.6.3 内测版

负责：本版发行内容、安装方式与已知覆盖边界。不负责：任务进度或重复验证记录。更新时机：本版发布前核对最终内容；发布后只纠正历史事实。

- 修复账号连接出现 429：已登录组件按账号、设备和组件分别限流，避免视觉节点、驻留和控制台共用网络请求额度；登录限流使用可信代理解析后的客户端地址。
- Windows 会话维护遵循服务端等待时间，临时失败保留登录并延后重试，恢复后清除对应错误提示；真实登录撤销仍会退出。
- 修复电脑原始时间偏快时新告警被发件箱立即清除：事件生成与队列过期判断共用 NTP 校正时间，保持原来的 30 秒实时有效期。
- Windows 每次连接先登记来源，收到心跳回执后再发送队列告警；未知来源暂时拒收时保留原事件 ID，按心跳重试，不再直接丢弃。
- 服务记录事件拒收原因，Windows Release 保留有大小上限的告警拒收日志，方便核对过期、来源登记和存储失败；不记录凭据或图片。

本版发行范围为 Windows 整包、Android 相机推流节点和通知节点两个签名包，以及统一服务／Web。相机与通知节点本轮只同步版本，没有新增业务功能；旧 Android 控制台继续保留 0.6.0 发行元数据。

Windows 完整解压后运行根目录 `VisionGuard.Detector.Windows.exe`；包内含 modern 与 Windows 7 SP1 x64 legacy 运行时。Android 使用同签名包覆盖安装。完整修复需要同时更新视觉节点与统一服务；仅更新客户端不能消除服务端旧限流配置。

本版为内测。构建与自动化回归不替代实机告警、控制台截图、通知收件、声音与重连验收；实测漏传的唯一触发原因尚未确认，覆盖边界见[验证记录](../90-验证记录.md)。
