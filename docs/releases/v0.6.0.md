# 0.6.0 内测版

- 发行客户端内置正式服务地址，登录只填写账号和密码。Android Debug 与 Windows 显式隔离环境保留测试地址入口。
- 首次登录按“设备代号-组件简称-序号”命名，简称为视觉、相机、控制、通知；账号内序号从 001 递增。进入程序后可修改本机名称，同一设备重新登录保留名称。
- 内置管理员 `xgwnje`，现有账号沿用密码；全新安装生成私有随机初始密码。Web 与 Android 控制台支持创建、启用/禁用账号、重置密码及设置管理员权限，保护最后一个有效管理员。
- 所有组件沿用中文名称、共用青色应用图标和黑白灰＋青色主题，功能图标统一使用 Lucide。

下载附件包含 Windows 整包、相机推流节点、Android 控制台及通知节点。Windows 解压完整目录运行主入口；Android 使用相同签名覆盖安装。统一服务和 Web 在正式服务部署。内测不承诺旧协议与数据兼容。
