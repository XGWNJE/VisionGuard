# VisionGuard v0.7.1

负责：本版发行范围和安装说明。不负责：完整验证报告。更新时机：本版发行内容变化时。

## 本版内容

- **视觉推理节点主界面重排**：从「上两栏 + 下两条」整理为「上两栏 + 底部一条」。底部状态带左段是与预览同宽的等宽数据格（实际帧率 / 检测目标 / 单帧耗时 / 置信度 / 采样 / 冷却 / 模型 / 目标），右段是与来源列表同宽的连接状态与应用入口，两处分界与上方对齐；主预览也改成与来源列表同规格的面板（48dp 表头 + 分隔线 + 16dp 内衬）。
- **来源、参数、遮罩合并成一个「来源抽屉」**：点来源行切换预览，行尾方键打开抽屉；抽屉用拨档切来源 / 检测参数 / 遮罩三页，页脚按页切换，参数与遮罩草稿互不影响。
- **逐来源启停**：每行来源自带 ▶ / ⏸，只影响这一路；整体启停压板移除，来源列表表头在有来源运行时提供「全部停止」方键。
- **本机相机默认在列表里**：进入界面时自动登记，不再需要手动「添加来源」；远程镜头仍由控制台绑定相机推流节点后下发。
- **提示统一为悬浮区**：运行时消息、来源错误、性能与恢复警告合并成预览面板上层的一条悬浮提示，不再挤压画面、列表与状态带；消息可关闭，长文最多三行。
- **参数解释就近可查**：各参数区块标题右侧有「?」，点击跳到帮助页对应条目；帮助扩为 8 条（运行与启停、检测参数、模型档位与下载、检测目标、隐私遮罩、远程来源与绑定、连接回执与声音、权限与后台）。
- **交互与可达性修正**：遮罩拖画需拖动超过阈值才新建（轻点不再造碎遮罩）、选择 / 移动模式点空白不再清掉选择、遮罩框与把手进入抽屉焦点环；有确认框时 Escape 不再连带关闭抽屉；关闭抽屉统一归还焦点；快捷行与目标 chip 补齐 48dp 触点；按键去掉涟漪并恢复按压位移反馈；拨档补选中语义；抽屉宽度跟随父约束。
- **无来源时直接进主界面**：删掉独立的「还没有来源」空态页。
- 发布 Windows 视觉推理节点、Android 相机推流节点、通知节点、视觉推理节点，以及统一服务 / Web。

## 安装与检查

更新各客户端并刷新[线上控制台](https://visionguard.xgwnje.cn/console/)。各端「关于 / 版本」当前应为 0.7.1。

- **Android 视觉推理节点**：可在应用内「设置 → 维护 → 检查更新」升级；本次发行含 `VisionGuard-Inference-v0.7.1.apk`。
- **界面变化**：来源、参数与遮罩统一从来源行的方键进入；本机相机默认已在来源列表中；参数说明统一在帮助页查看。

构建、发行附件与真机证据见[验证记录](../90-验证记录.md)。
