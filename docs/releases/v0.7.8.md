# VisionGuard v0.7.8

负责：本版发行范围与升级说明。不负责：完整验证报告。更新时机：本版内容变化时。证据见[验证记录](../90-验证记录.md)。

## 本版内容

- 相机推流节点：Web 复用控制台官方 Neutral／Radix Nova 组件，Android 保留原生 Compose；横屏左控制右预览、竖屏上控制下预览，启停固定可见，关闭预览保持区域。
- 字体与统计：相机两端内置 Noto Sans Simplified Chinese 与许可，区分本机入队、服务收帧及两端丢弃；目标选择、登录、帮助、账号与外观采用同一风格。
- 全屏：Android 启动及返回前台隐藏系统状态栏和导航栏，相机全屏弹窗同步处理；Web 首次点击或确认按键请求全屏，保留全屏切换入口，主动退出后不强制重进。浏览器不支持或拒绝时仍可正常使用页面。

## 升级说明

发布 Windows 统一包、Android 相机推流节点／通知节点／视觉推理节点，以及统一服务与两端 Web。客户端可在应用内检查更新并按系统提示确认安装，也可手动安装对应发行包。

协议版本为 **0.7.8**；服务升级后旧版本节点需要同步更新，Web 页面刷新后生效。其他组件的全局字体与默认全屏尚未实施。
