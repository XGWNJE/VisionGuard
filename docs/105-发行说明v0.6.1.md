# 0.6.1 内测版

负责：本版发行内容、安装方式与已知覆盖边界。不负责：任务进度或重复验证记录。更新时机：本版发布前核对最终内容；发布后只纠正历史事实。

- Windows 加密连接校验证书可信性、有效期与域名，认证前拒绝异常连接；保留 Windows 7 SP1 x64 的 legacy 运行时。
- 同账号的独立 Web 会话可以同时在线；刷新、重连与退出只影响自身，会话撤销与硬件重复连接保护保留。
- 通知节点遇到疑似中断先探测或重新连接，确认失败后报警；修复旧时间戳、过期回调、重复报警与恢复状态。
- 相机推流保留真实发送、接收与丢弃统计，修复重复绑定、额度、确认、首帧时序与媒体健康恢复。
- Web、Windows、Android 相机与通知节点支持跟随系统、浅色、深色并保存选择；沿用紧凑界面、青色与官方 Lucide 图标。检测目标按真实模型标签提供中文搜索多选，参数草稿独立，确认保存并反馈结果。
- Windows、Android 相机与通知节点检查 GitHub 稳定版更新，校验大小与摘要；支持取消、暂存、安装交接与 Windows 失败回退。

下载附件仅包含 Windows 整包、Android 相机推流节点和通知节点。Windows 完整解压后运行根目录 `VisionGuard.Detector.Windows.exe`；Android 使用同签名包安装，由系统确认安装权限与结果。Web 桌面端是唯一主要控制台；旧 Android 控制台保留源码、服务兼容与必要回归，退出默认发行。

统一服务与 Web 一并部署，不采用客户端式自动更新。内测不承诺旧协议与数据兼容。真实相机已验证输出画面，未以无识别对象的现场证明完整报警链；Win7 实机、高对比度、通知锁屏保活及可听声音等覆盖边界见[验证记录](90-验证记录.md)。
