# 控制台与通知节点

负责：控制台与通知节点。不负责：其他模块事实、任务状态或重复验证记录。更新时机：该主题源码或约束变化时；历史发行说明只纠正事实，不随当前版本改写。


跨端管理由 `receiver/web/` 的 Web 控制台承担，后台收件与声音由 `notifier/android/` 的 通知节点承担；Android 控制台已淘汰。职责见[项目概览](10-当前架构.md)，证据及未覆盖项只在[验证报告](90-验证记录.md)维护。

全部控制台与通知页面、表单、底部面板和应用弹窗遵循[统一 UI 规范](70-UI设计规范.md)。相机和通知两个 Android 应用复用 `android-shared/` 的完整 Material 主题与状态颜色，Web 使用对应 CSS 变量；浅深色、文字层级和控件状态共用同一规范。

## Web 控制台

同账号可同时登录多个独立 Web 会话，包括复用设备登记的会话。重连按会话替换，刷新与退出不影响其他会话；密码修改、重置、禁用或管理员权限变化撤销账号全部会话。旧连接的截图队列与控制请求在替换、断开和撤销时清理，旧 HTTP/WS 回调不能污染下一会话。

控制台显示“正在连接”与“正在认证”，网络连接超时和认证响应超时分别提示并重试；服务端明确返回认证超时也不视为会话失效，实际拒绝或撤销会话仍要求重新登录。建连限时 12 秒，打开后认证独立限时 12 秒；重试通过独立定时器按 1、2、4、8、16、30 秒退避，成功后重置，退出 / 会话切换取消待执行计时。浏览器后台节流仍可能延迟定时回调。3 秒心跳和已认证后的服务响应监测保持原规则。

控制台默认输出 `[RelayAuth]` 阶段日志，区分未建连、已发送认证但未收到结果及已认证后的服务响应超时。每次尝试使用随机标识关联服务端；当前标签页以 `sessionStorage` 保存最近 100 条，每次记录淘汰超过 24 小时的条目，刷新后仍可读取。仅保存时间、阶段、耗时、关闭代码及固定原因，不保存账号、密码、token 或业务消息；存储受限时仍输出浏览器日志。取证方法见[认证连接诊断](60-构建验证与发布.md#控制台认证连接诊断)。当前线上内容以[验证记录](90-验证记录.md)为准，源码改动不代表部署完成。

- 服务同源 `/console/`，账号密码登录后由服务分配 `console/console/web` 身份。外部使用 HTTPS/WSS，回环与私有 IPv4 局域网测试允许 HTTP/WS。会话通过不可导出的 AES-GCM 密钥加密保存在同源 IndexedDB；有效期内刷新恢复原凭据并重新鉴权，恢复阶段不先显示登录页。默认从本次登录成功起计 24 小时，到期、退出、撤销或账号失效后清除会话，不自动续期延长；后台标签页恢复到前台时补查到期。临时网络失败保留未到期会话，由连接流程重新鉴权。保存登录会话需要 HTTPS 或 localhost 安全上下文及可用的站点存储，保存失败时明确提示并撤销新签发凭据。会话保持与密码记忆独立；“记住账号密码”默认未勾选，成功登录后用不可导出的 AES-GCM 密钥和密文保存在同源 IndexedDB，下次自动填入，仍须点击登录。取消勾选立即删除密文与密钥，退出保留记忆，本机改密成功后清除旧记忆。记忆能力要求 HTTPS 或 localhost 安全上下文，浏览器存储可被同源脚本使用。设备、事件、截图、控制、通知范围和显示时间按账号隔离，不提供免鉴权测试后门。
- 设置提供退出、修改密码和本机名称；节点详情支持命名与解绑。管理员另有“账号管理”，可创建、启用/禁用账号、重置密码及设置管理员权限。相机推流节点提供目标视觉推理节点选择，唯一推理节点自动关联；其推流状态独立于 Windows 来源的检测状态。
- Web 横屏显示侧导航、节点列表与详情；竖屏及窄窗口使用底部导航，节点列表与详情切换，详情保留返回入口。优先保障 8.8 寸平板，交互触点至少 48px，来源表格局部滚动。搜索名称或 ID，按视觉、传感器、通知类型筛选；登记但未连接的节点保留为离线。控制台断线时清除实时状态，节点与通知范围不保留旧在线标记；登记身份、接收范围和历史仍保留，重新连接后同步当前状态。
- 节点和视觉来源分别显示实际状态、当前参数及可用操作。依据能力显示启停、停止报警、打开/关闭检测程序和配置；通知节点提供“确认当前报警”，通过持久化队列确认当前项；排队报警继续播放。相机提供推流启停，开始前必须绑定视觉推理节点、在设备上授权摄像头并保持相机前台。操作显示转发与实际执行回执，超时表示结果未知。视觉来源属于父设备，携带来源 ID 操作；来源运行时先暂停再修改参数。
- 节点工作区顶部显示状态、控制对象、启停 / 报警确认与可用的应用操作；下方分为运行与事件、参数与配置、设备管理及当前节点回执。桌面运行区并列显示检测来源与最近历史画面，窄屏来源行同时提供状态、帧率、启停与参数入口；相机运行区显示推流关联，通知节点显示接收范围及编辑入口。来源参数入口直接定位配置页，切换工作区保留草稿。视觉配置提供模型选择、置信度滑块、冷却预设与 1–300 秒细调、1–5 FPS 档位和目标多选；传感器提供协议允许的置信度及冷却。保存后以检测节点状态与 completed 执行回执核实，不提前把转发显示为成功。
- 事件列表包含最近 100 条历史及实时事件，区分视觉、传感器与中断类型。无图事件显示文字；截图独立到达后按事件 ID 关联，携带本次凭据从同源拉取，退出后释放临时图片。历史不会触发声音。
- 「设置 → 统一时间」修改账号内的告警显示标准，默认北京时间（UTC+8），可切为 UTC（UTC+0）；服务保存后向 Web 和通知节点推送，重连重新同步。节点响应时间、告警列表与详情使用相同标准，详情显示完整日期和时区。
- 通知范围按通知节点目录与编辑区组织，切换节点保留未保存的选择，保存入口位于范围选项旁；为每个已登记通知节点分配全部或指定检测节点 / 视觉来源；离线身份仍可配置，指定空集合表示不接收。范围由服务端保存，通知节点下次认证读取。
- 跟随系统／浅色／深色共用布局与语义色，保存本机选择；规范见[统一界面](70-UI设计规范.md)。实现入口为 `src/main.tsx`、`src/useRelay.ts`、`src/protocol.ts`、`src/style.css`。

## 通知节点

源码为 `notifier/android/`，工程名 `VisionGuard.Notifier.Android`，独立包名 `com.xgwnje.visionguard.notifier`。应用专用于 VG 报警，不包含本机通知关键词监听、应用过滤、延时报警或 Vigil 的 GitHub 更新入口。原 Vigil 的代码与现有改动保留在原仓库，不合并分支、不覆盖安装或迁移数据。

通知节点使用 VisionGuard 自身 GitHub 稳定版入口，精确选择 `VisionGuard-Notifier` APK；与相机共用取消下载、大小／摘要、包名／版本／签名校验及私有缓存暂存。点击检查更新重新查询发行列表，以系统实际安装版本判断；下载与安装前再次核对，同版本或更旧版本清除待更新状态，不下载或交接安装器。重新检查或打开应用时，已有有效安装包重新校验后恢复为可安装状态；检查本身不下载 APK。安装前在后台重新校验，要求回到前台交接，校验期间禁止重复执行并支持取消；缓存损坏退回下载状态，退出时在后台释放网络资源。安装权限和最后安装由系统处理，请求或打开安装器不显示为安装完成。

- 账号登录自动获得 `notifier/notification/android` 身份。两个 Android 组件的 Release 内置正式服务地址，只有 Debug 提供隔离测试地址；共用 `android-shared/` 的登录、登录后本机改名、改密与 Keystore 加密会话。登录页提供默认未勾选的“记住账号密码”，成功登录后按服务和组件加密保存并在下次登录填入；取消即清除，退出保留，本机改密成功后清除旧记忆。会话与记忆排除备份及设备转移，既有会话恢复方式不变。账号管理由 Web 控制台提供；缓存、去重、记录与队列按服务、账号和设备分区。
- `NotificationNodeService` 维持独立前台连接；实时事件按稳定 ID 与去重标识一起落盘后才回收件确认。队列满或写入失败不确认，允许原期限内重试；确认后重复事件不再入队。
- 普通 Android `Service` 类型的 `AlarmPlaybackService` 消费持久化 FIFO 队列，无需通知使用权。声音来自系统铃声、内置目标提醒或导入/录音库，播放 1–10 次；确认、达到次数或播放失败结束当前项，再进入下一项。持久化失败保留当前项，不能把收件回执当作声音证明。
- 最近有效响应后 45 秒无响应先标记疑似中断，发送带随机标识的心跳探测；探测无响应后重新连接，新的连接尝试也失败才报警。使用单调时间；锁屏后计时或消息回调长时间延迟会重新探测，不按睡眠积累时间立即报警。每次尝试独立计时，连接世代隔离旧回调；中断标识与队列原子持久化，长期离线或服务重建不重复报警，认证或新探测确认恢复后清除标识。
- 统一时间标准由控制台设定、服务同步并在本机保存；最近记录、完整历史和弹窗显示同一时区。接警首页采用控制 / 最近报警双区，横屏左右、竖屏上下排列，大字号单列滚动；接警启停常规字号固定在控制区底部，铃声、循环次数和铃声库直接操作。顶部提供账号 / 帮助 / 设置图标，完整范围、服务地址和时间标准收进接警帮助。最近报警显示来源、时间及真实结束方式；收件计数不表示声音已播放。应用提供跟随系统／浅色／深色，持久保存并同步系统栏，手动选择优先系统。
- 告警确认界面以“发现什么”为中心。视觉事件从已有 `detections` 中选取最高合法置信度对象，随队列持久保存；同分保持上报顺序，不从摘要猜目标。人 / 汽车用生成的透明位图示意，其他对象保留实际类别文字，其他类型告警保留事件名称；位图不是事件截图。图像、文字与空白均为确认停止触区，详情入口独立；确认保存失败保留告警。来源、摘要、时间与置信度默认收在详情，实际画面与完整检测结果在控制台查看。
- 版本直接读取根 `VERSION`；共享 VG 的私有 Android 签名配置，缺签名材料的 Release 构建拒绝执行。应用启动及手动检查自身稳定版更新；正式发布流水线包含独立通知节点 APK 和 `android-notifier` 查询键，不对接 Vigil 的发行版。

导入音频的自动展示名及铃声重命名均采用 64 个 UTF-16 单元上限；自定义输入与本机库保存再次校验，拒绝空名称、控制字符和超限值。与其他名称的计量方式统一见[数据边界](70-UI设计规范.md#本地预览与数据边界)。


## 控制能力与本机授权

Web 是系统业务数据和控制的最高入口；同账号可管理节点名称、解绑、来源检测启停和参数、推流关联与启停、相机配置、通知接收范围、声音策略 / 音频库、当前报警确认、统一时间、临时缓存盘点 / 清理及 Windows 打开/关闭。管理员可管理账号。服务统一核对账号、目标能力、在线状态、来源及请求关联；转发不表示设备执行成功。

节点的「参数与配置」提供相机 480p / 720p、显示 / 隐藏预览和推流期间屏幕变暗；修改规格前先停流。通知节点提供默认铃声、1–10 次播放，以及音频库导入、节点试听 / 停止试听、自定义条目改名 / 删除；内置音频不能改名或删除，已被默认策略或报警队列引用的文件不能删除。策略变更只作用于之后入队的报警。所有保存等待 completed 回执，并由后续心跳读回当前值；试听回执不证明现场声音可听。

音频条目只暴露不含本机路径的 ID。自定义库最多 100 项，展示名最多 64 个 UTF-16 单元；远程导入支持 MP3 / WAV / OGG / M4A，文件不超过 512 KiB、可解码音频时长不超过 60 秒，服务校验格式和大小，节点再次解码核验后保存。导入期间登录变更取消操作；录音期间禁止远程导入，报警 / 录音期间禁止试听，收到报警会停止试听。Web 操作与本机声音设置同步显示。

系统权限、摄像头前台、设备解锁、选择其他系统铃声、录音与麦克风授权仍须本机操作；Web 显示操作条件与引导。远程能力要求服务、Web 与对应节点使用本分支的同一契约。步骤见[自行验收](60-构建验证与发布.md#远程配置自行验收)。

## 临时缓存入口

Web 设置页管理本账号的服务截图缓存；管理员另有旧公共截图目录入口。在线节点的「设备管理」按能力展示缓存盘点和回收按钮，收到真实 completed 后展示删除数、字节和失败数；不把转发 / 超时当作完成。通知节点可回收当前账号超过 24 小时的诊断导出，以及未被更新器占用、超过 7 天的安装包暂存；分享和安装文件有保留期限，音频库、报警与活动日志受保护。容量、回滚及自行验收步骤统一见[服务器资源维护](60-构建验证与发布.md#服务器资源维护)。
