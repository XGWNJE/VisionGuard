# 路线图

负责：后续方向与优先顺序。不负责：本次任务进度、当前模块实现或验证证据。更新时机：owner 确认新的方向、范围或优先级时。

Web 桌面是唯一主要控制台；Android 相机与通知节点继续支持手机和平板。旧 Android 控制台保留源码与服务兼容，停止新增功能，退出未来默认发行。

| 顺序 | 后续方向 | 启动条件 |
|---|---|---|
| 1 | 完成本次十分支的软件整合与设备验收 | 按[任务清单](06-任务清单.md)推进，证据只写[验证记录](90-验证记录.md) |
| 2 | 现成传感器、开发板、电池的硬件原型；2–8 米慢走和快速骑行、供电与续航 | 联网和告警现场验证之后确定组合，不提前设计 PCB |
| 3 | 采集卡与其他摄像设备的视频输入 | 按真实需要逐类接入统一节点；窗口、选区、遮罩仍留 Windows |
| 4 | 平板视觉推理、传感器融合、结构与电路板优化 | 有设备性能与使用频率证据后再细化 |

方向未排期，不表示已实现。原 Vigil 仍独立维护；架构职责见[当前架构](10-当前架构.md)。
