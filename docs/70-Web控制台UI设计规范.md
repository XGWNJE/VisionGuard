# Web 控制台 UI 设计规范

负责：Web 控制台的设计标准、组件组织与适配范围。不负责：业务契约、任务和验证证据。更新时机：设计或实现边界变化时；实际检查只记在[验证记录](90-验证记录.md)。

## 控制台设计基准

Web 控制台采用官方 [shadcn/ui](https://ui.shadcn.com/docs) Neutral／Radix Nova，直接组合 CLI 获取的真实组件；配置在 receiver/web/components.json，组件在 src/components/ui/。使用语义 CSS 变量与官方 [Vite ThemeProvider](https://ui.shadcn.com/docs/dark-mode/vite)，以根 .dark 类切换跟随系统／浅色／深色并保存本机偏好。正文与次级文字使用官方 foreground／muted-foreground，不另设页面调色板。

- 本地打包 Geist，中文回退系统无衬线；正文 14／20、辅助 12／18、页面标题 24／32、CardTitle 16／24，单位 rem。字体与组件许可证随 public/third-party/ 分发。
- 间距 4／8／12／16／24／32；根圆角 .625rem，控件和卡片采用官方尺寸、圆角与变体。按钮、输入、下拉默认 2rem；保留字号缩放和内容滚动。
- 仅针对 16:10 横屏设计与验证；布局使用弹性尺寸与滚动，不绑定分辨率，不增加窄屏、竖屏、单列或折叠导航。手机 Web 在浏览器允许时请求横屏锁定。
- 文案仅保留必要标题、字段、操作、状态与错误，删除教程、重复提示和设计说明。状态含正常、悬停、按下、选中、禁用、焦点、加载与错误；颜色与图标辅助文字。

## 控制台结构与组件

主导航固定展开，宽约 13rem，分「工作区」与「管理」：节点总览、事件记录、通知管理；设置、管理员专属账号管理。节点总览是表格入口，打开节点后进入独立工作长页，面包屑返回总览；不再保留可拖宽目录与详情并排的旧工作区。

| 页面 | 信息与操作组织 |
|---|---|
| 节点总览 | 在线／登记、检测、推流与事件摘要 → 搜索／类型／在线筛选 → 节点表；主操作为打开节点，通知节点进入通知管理，浏览器相机入口归此页。 |
| 节点长页 | 来源与检测（发布端为来源与推流）→ 检测规则 → 设备与关联 → 维护与诊断；逐来源启停紧邻来源，全部来源控制独立；相机配置与推流同组。 |
| 事件记录 | 统一筛选在上，列表与所选事件证据并排；截图、节点来源、完整时间、检测结果、收件回执集中，详情可打开节点。 |
| 通知长页 | 选择通知节点；接收范围 → 报警与声音 → 音频库 → 设备与维护。未提供的能力不设空壳入口，离线范围仍可保存。 |
| 设置长页 | 账号与安全 → 本机与外观 → 服务与维护；本机名称、外观、服务时区和缓存各归所属职责。 |
| 账号管理长页 | 账号列表 → 创建账号 → 所选账号设置；表格操作定位本页表单，保留创建、权限、启禁用与密码重置。 |

- 二级菜单只滚动定位，所有当前对象设置连续展示，滚动同步高亮；不写“本页目录”等显然提示，不用 Tabs、折叠、侧栏或编辑弹窗拆分这些分组。危险确认及文件选择保留必要临时交互。
- 以 1600×1000、1280×800 两档 16:10 检查；页内定位约 9rem，正文使用剩余空间并限宽约 68rem。统一正文滚动链，定位菜单固定；页面内边距与分组间距 1.5rem，内容按职责分组，不多层嵌套卡片。
- 页面标题 24／32、分组标题按官方 CardTitle、正文 14／20。按钮、Input、NativeSelect 用 Nova 默认 2rem；采用官方尺寸变体，不用 padding 叠加出不同高度。同组标签、输入和操作分别对齐，表格操作间距 .5rem，长名称换行与详情滚动。
- 组合官方 Sidebar、Breadcrumb、Card、Table、FieldGroup／Field、Input、NativeSelect、ToggleGroup、Checkbox、Separator；反馈使用 Alert／Empty／Skeleton，确认使用 AlertDialog。只为业务布局与定位编写必要代码，不复制线框的示意控件样式。
- 全部功能继续接现有 API、权限与能力判断；逐项保存和规则草稿保留，切对象或离开前可保存、放弃或继续，保存离开等待执行完成。转发、成功、失败与结果待核实分别显示；不因点击而宣称成功。

## 本地预览与数据边界

控件有明确标签，密码默认遮罩；当前值与草稿分开，保存读取当前输入。危险操作先确认并默认取消，普通弹窗支持返回／Escape 及焦点恢复；活动报警仍只通过既有确认规则停止。空态、加载、离线、失败、权限与执行结果显示真实状态；缺值为“未报告”。

| 字段 | 当前合法范围 |
|---|---|
| 设备名、来源名、音频展示名 | 非空，最多 64 个 UTF-16 单元，禁止 U+0000–U+001F；emoji 通常占 2 单元 |
| 自定义音频库 / 远程导入 | 最多 100 项；展示名最多 64 个 UTF-16 单元；MP3 / WAV / OGG / M4A，远程文件最多 512 KiB、60 秒 |
| 每视觉推理节点来源数 | 1–16；未报告来源可为空，不能据此伪造节点支持 0 路采集 |
| 来源置信度 / 冷却 / 采样率 | 10–95% / 整数 1–300 秒 / 整数 1–5 FPS |
| 来源异常短文 / 事件摘要 / 目标框数 | 最多 256 / 256 个 UTF-16 单元 / 100 个 |
| 目标集合 | 最多 256 项、每项 64、总长 4096 个 UTF-16 单元；至少选一项 |

名称按现有契约校验，不静默截断保存；合法长名称和错误可换行或滚动。数值校验范围、精度和有限性，来源运行时不可修改的规则保持只读。数据语义、权限及 API 契约不因布局调整变化。

控制台本地 UI 检查走 scripts/ui-preview.ps1 的隔离服务，只有有数据场景显式启用 -MockData；模拟节点、截图及回执不证明真实检测、收件或声音。缓存只读复用 server/data/{models,releases}。真实链路与 UI、构建、设备和生产验证分开记录，入口见[构建验证与发布](60-构建验证与发布.md)。

## 图标

控制台使用官方 lucide-react 1.49.0，不手绘或混用图标。图标随语义文字色，独立图标操作有准确名称，许可证随组件分发；品牌素材见 [icon](../icon/README.md)。

## 实现与核验

- 控制台：receiver/web/src/components/ui/、components/theme-provider.tsx、ConsoleLayout.tsx 与各工作页；theme.css 提供与 Web 相机共用的官方主题，style.css 维护控制台字体与业务布局。控制台仍使用 Geist，相机字体见[相机专题](40-相机推流节点.md#界面与字体)。
- node scripts/check-ui-theme.js 在 CI 核对控制台官方主题、文字对比和组件引用。静态检查不替代实际窗口或设备目检；控制台布局验证仅限本轮实际检查的 16:10，不推断其他比例。
