## Android 两份实现

共同起点为 `main` 的 `9927c5f`；工程均为 `detector/android-inference/`，登录组件均为 `android-inference`。表格描述源码能力，构建及运行覆盖见[验证记录](90-验证记录.md#android-推理双分支核对2026-10-09)；本分支详细事实见[Android 推理专题](31-Android视觉推理节点.md)。

| 项目 | DeepSeek | Codex |
|---|---|---|
| 最后源码提交 | `d01aae7`（另有存档文档提交） | `0bc7ec1`（另有预览文档提交） |
| 画面来源 | 本机相机、统一服务远程镜头 | 本机前 / 后镜头；同一镜头多路配置，不同时开前后镜头 |
| 推理后端 | 尝试 NNAPI，注册或会话创建失败回落 CPU | CPU |
| 后台生命周期 | 前台服务维持运行意图，进程重建恢复 | 切后台 / 锁屏停止，回前台手动开始 |
| 设备级参数保存 | 无来源标识时修改第一个来源 | 无来源标识时对全部来源原子校验和保存 |
| 模型输出检查 | 按展平长度识别两种输出布局 | 校验模型输入与 `[1,300,6]` 输出形状 |

两份实现均有账号隔离、模型下载、参数边界、遮罩、报警持久队列、接受回执后发送截图、心跳与控制台远控。正式包名相同（`com.xgwnje.visionguard.inference`），两份正式 APK 不能作为两个应用并存；比较安装应使用各自的隔离预览身份。它们各自可与相机推流、通知应用并存。
