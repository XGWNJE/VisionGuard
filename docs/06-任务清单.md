## 当前状态

已发布组件由 `main` 承接，当前发行版本 0.6.12（已部署到 VPS 并核对公网门禁），保留完整 0.6.11 回滚点。`main` 已合入 Android 推理实现、几何空间界面规范、Web 交互原型、推理量化与真机加速测量（`de9ff78`）、Web 相机推流节点（`5b41dea`）、推理加速落地全套（端侧锚点解析、LiteRT 加速链路、多路限制、GPU 与量化产物投放）与推理节点发布接入。以上均为本地提交，未推送。

推理路线已按实测定案（口径、数据与限制见[优化专题](32-推理框架与模型优化.md#验收口径)）：**正式档 = ONNX Runtime · CPU 4 线程**（FP32 或 INT8 本体都能跑，量化版更快更省内存）；**加速档 = LiteRT GPU + 截断图**，只在有 GPU 产物且已下载的模型上自动启用，用不了如实回落 CPU。NPU 不申请厂商则无路可走。服务端已投放 12 个 FP32 本体 + 6 个量化本体 + 1 个 GPU 产物。
