### 推理加速路线评估（进行中）

owner 口径（本轮）：**跳过登录鉴权**，测量入口在登录之前、只用本机算力与包内模型；最终产出**两套搭配**——同质量过关下 **CPU 档最快** 与 **GPU 档最快**。GPU 复测按分诊 + 止损线推进，**成功 = 编译通过并跑出可用读数**，加速门槛（≤ 同运行时 CPU 的 0.70×）单独报告。

- [ ] **全矩阵真机测量（读数已齐，受控复测中）**：三包已在真机 kpad2（Xiaomi 26048RP6AC / MT8910 / API 37）跑完完整档位（A/B/C 各 4 模型 × 19 档），报告与日志在 `.local/model-quant/accel-reports/matrix-{A,B,C}-*.txt`，汇总脚本 `.local/model-quant/summarize-matrix.py`。
  - 读数漂移较大（同配置跨轮可达 40%，如 `yolo26n_320_int8` 4 线程 5.9 / 7.9 / 8.4 ms），因此**定案用受控复测的同包多轮中位**（亮屏低亮度、连续三轮、轮间静置 30 秒），不取单轮最小值。
  - 本轮顺带修掉测量侧两个缺陷：① LiteRT 老 `Interpreter` 入口在真机**全部 CPU 档**报 `BufferUnderflowException`（`interpreter.run()` 后缓冲位置停在末尾，读取前需 `rewind()` 并批量取），修复前那些档位在真机上一条读数都没有；② 测量包此前只出耗时，现每档附**质量行**（person 数 / 最高分 / 最高框）。
  - 安装通道：MIUI 拦住 adb 静默安装（`INSTALL_FAILED_USER_RESTRICTED`），需设备端开启「USB 安装」，确认框由脚本点掉；每次重装都会清掉登录态与应用数据。
- [ ] **GPU 复测：已打通，但不达标（本轮定案）**：**根因是图尾的 int64 后处理，不是量化**——真机原生日志里拒绝的算子是 `CAST/RESHAPE/TILE(INT64)`、`GATHER`、`GATHER_ND`（全在 `wa/model.23/TopK/Tile/Expand`），而 LiteRT 2.3.0 的 `CompiledModel` **只接受整图编译、没有 CPU 回退开关**（`GpuOptions` 全部字段已核），本分发也没有任何 delegate 通路（`Interpreter.Options` 无 `addDelegate`、包里无 delegate 类）。
  - 决定性对照：原始 `yolo26n_320`（398 节点，带图内 NMS）四档全部 `Failed to compile model`；把图在 `/model.23/Concat_3_output_0`（`[1,84,2100]`）截断后（378 节点，int64 尾全消失）**四档全部出读数**：默认 17.3 / FP16 20.3 / 纹理权重 **14.4** / 关外部张量 15.0 ms。截断模型同样带 `392 GPU + 29 CPU` 分区却编译通过，所以"29 个不支持算子导致整图拒绝"的旧解释已修正。
  - **不达标**：同轮 CPU 档 7.4 ms（`LiteRT · 加速器 API CPU + XNNPACK 4 线程`）与 13.1 ms（`ONNX · CPU 4 线程`），门槛（≤ 同运行时 CPU 的 0.70×）不满足；采用还要付"双格式（ONNX 走 CPU / 截断 TFLite 走 GPU）+ 新锚点解析分支"的长期成本。
  - **已实测封死**：int8 边界量化（框与分数在同一张量、同 scale，分数被压成 0；框坐标校准实测 -42~468、分数 0~0.954）、int16 激活（转换期 `Quantized dimension ... Got 3 and 0`）、float16（加载即报 `TRANSPOSE` 类型不一致）、`modify_model_interface`（`called on a model without quant/dequant`）。
  - 若将来要继续：端侧补一条 `[1,84,2100]` 锚点解析 + NMS（现有锚点分支是 `[1,84,N]` 的 YOLOv5u 语义，不能直接套）。工具与产物在 `.local/model-quant/{truncate-onnx-nms.py,build-anchor-tflite.py,anchor-tflite/,venv-tf/}`。
- [ ] **定主线推理路线**：等全矩阵与 GPU 复测有结论，再决定主线用哪条。这一步属发布行为，需 owner 明确授权后执行。
