# 几何空间界面规范

负责：中性灰 / 青色几何空间界面的落地规范（控件清单、几何尺寸、业务规则、可达性）。不负责：原型运行说明、任务状态、验证结果或 Android 实现事实。更新时机：界面方向、控件清单或规范数字变化时。

方向已由 owner 定稿：用平面几何表达空间关系，模拟真实物理操控，但不做 3D、不做拟物。**概念素材已按 owner 要求丢弃**（2026-10-09），本文件与预览内的「落地规范」页是唯一依据。原型运行与改动规则见[原型说明](../prototypes/android-inference-geometric/AGENTS.md)，Android 实现事实见[Android 视觉推理节点](31-Android视觉推理节点.md)。

预览入口 `prototypes/android-inference-geometric/`，三个页签：节点预览、控件设计稿（32 项）、落地规范。原型只做交互模拟，不连生产服务、不持久化凭据。

## 适用设备与密度换算

- 目标设备 8.8 英寸、16:10、触摸屏。屏幕对屏约 189 × 118 mm。
- 按 2560 × 1600（约 345 dpi、密度 2.0）计算，CSS 视口为 1280 × 800，与原型 `tablet-frame` 的 `max-width:1280px`＋`aspect-ratio:16/10` 一致：预览像素即设备像素。
- 换算率 6.77 CSS px/mm，故 **48px = 7.1mm**。这是本项目触点的绝对下限。
- 设备短边按 dp 计约 745dp，低于 Android 端宽屏阈值 840dp；宽屏三栏的实机判定与密度相关，实现时按 dp 判断，不照搬预览宽度。

## 全屏与头部

owner 要求（2026-10-10）：**全屏运行、不要头部标题行**，把空间让给有用内容。

- 不显示系统状态栏；用户从屏幕上缘下滑仍可临时呼出，导航栏保留。
- 不使用顶部标题行：品牌与节点名不再单独占一行。
- 应用级入口（连接状态、使用帮助、全局设置、账号）放在技术信息带右端，与参数摘要同一行，每个入口仍是 ≥48dp 触点。

## 输入与可达性

- 触点下限 48px；8.8 英寸设备上 48px = 7.1mm，是交付底线，不因信息密度让步。
- 滚筒：拖动 / 滚轮 / ↑↓ / Home / End；端点是止挡而非循环；数字位置映射用连续正弦投影，禁用 3D 旋转。
- 滑轨游标可拖可点，方向键与 ± 键精调；精确输入在失焦和回车时校验，Esc 还原。
- 遮罩把手的 48 触点贴到图像边时自动内移，保证完整可抓；键盘方向键按 1% 步进。
- 默认取消聚焦；模态内 Tab 正反向都循环，Escape 关闭，关闭后焦点回到调用处。
- 系统减弱动态开启时，取消惯性、平移过渡与滚动动画，保留直接选择反馈。
- 长名称不靠悬停气泡：来源检查与设备名入口显示完整值，列表内单行省略。
