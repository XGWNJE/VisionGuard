# 几何空间视觉语言参考

负责：Android 视觉推理节点「看起来像同一套界面」的视觉底线（直角几何、描边、色板、图标、触点、动效基调）。不负责：布局与信息架构、控件清单、任务状态、验证结果或实现事实。更新时机：视觉底线本身变化时。

**布局、区域划分、控件数量与操作步骤不再受本文约束。** owner 于 2026-10-12 决定放弃原「几何空间界面规范」的硬约束：逐项尺寸表、32 项控件清单与「数字由契约测试断言」的条款随之下线，界面可以按使用效果自由重排。当前实现事实见 [Android 视觉推理节点](31-Android视觉推理节点.md)，通用规范见 [统一 UI 设计规范](70-UI设计规范.md)。

## 视觉底线

- **直角与描边**：面板、按键、抽屉一律直角（不用圆角胶囊），1dp 描边，不用阴影、渐变、发光或 3D 明暗。
- **颜色**：语义色只表达状态，不做装饰。色板与[统一 UI 设计规范](70-UI设计规范.md)同源：页面 `#F5F5F5` / `#121212`，面板 `#FFFFFF` / `#1B1B1B`，次级表面 `#EEEEEE` / `#282828`，正文 `#202020` / `#F2F2F2`，辅助 `#626262` / `#B3B3B3`，边框 `#DDDDDD` / `#3D3D3D`，主色 / 成功 `#087F83` / `#4FBCC1`，主色上的文字 `#FFFFFF` / `#062E30`。
- **图标**：只用 Lucide 官方线性资源（`1.49.0`，由 `node scripts/generate-lucide-icons.js` 生成），不手绘、不混用其他图标族。
- **触点**：任何可点元素 ≥48dp；信息密度不成为缩小触点的理由。
- **字号**：可点标签 ≥14sp，辅助与技术值 12sp（早期的 10sp 已废弃）。
- **动效**：拨档 160ms、抽屉 180ms、按压 110ms 的基调，按下位移 3dp，无涟漪；系统开启「减弱动态」时只保留直接反馈。
- **画面**：预览等比留边，不用旧画面冒充实时；遮罩与检测框画在画面坐标上，颜色取自主题。

## 与统一规范的关系

浅色 / 深色、语义色、图标与可达性底线沿用[统一 UI 设计规范](70-UI设计规范.md)；本文只补本节点特有的几何语言（直角、无涟漪、按压位移、等宽节奏）。统一规范里的「按钮与卡片圆角 8」不适用于本节点。

## 落地与验收

1. 视觉底线由人工目检与本文件表格对照，不再由数字契约测试拦截。
2. 界面结构与交互按[Android 视觉推理节点](31-Android视觉推理节点.md)的当前描述实现，观感与触摸手感仍由 owner 在真实设备目检。
3. 预览构建可用「设置 → 维护 → UI 验收」的模拟数据做界面走查（多来源、异常态与长文本）。

## 历史

- 2026-10-09：方向定稿为平面几何表达空间关系、不做 3D 与拟物；概念素材按 owner 要求丢弃。
- 2026-10-12：owner 决定放开布局与信息架构约束，本文由「落地规范」降级为「视觉语言参考」；原型 `prototypes/android-inference-geometric/` 保留为设计参考，其自测只保证原型自洽，不再约束 Android 实现。
