## 当前状态

核验日期：2026-10-04。开发分支为 `codex/roadmap-next`，当前版本 `0.5.2`。中文组件名与共用应用图标已交付，生产服务已替换，GitHub 四个发行包已发布，两台真机已安装。既有动态运行与报警流程证据属于 `0.5.1`；本轮安装、发布及公网结果单独列出。

统一主题已完成：Windows 视觉节点及内部启动器、工具窗口、提示与托盘，Web 控制台和三个 Android 应用采用黑白灰底色、青色主色及 Lucide `1.49.0`。规范见[统一 UI](../design/unified-ui.md)。已实际通过的检查获得 owner 认可，无需重复人工验收；未观察的状态不自动记为通过。

当前账号、设备身份、媒体、事件、控制、通知范围与时间标准契约已实现；相机推流节点、Windows 推理、控制台和独立通知节点的职责见[项目概览](10-project-overview.md)。物理传感器驱动尚未接入。

## 后续独立任务与未覆盖项

待人工/真机补齐的范围只保留当前未覆盖项：真实人员推理到真机通知的同事件闭环、可听声音、持续运行、网络/采集故障、厂商后台限制；当前镜头 720P、后台/锁屏停止及手动恢复、低亮度/收预览的耗电和发热。

业务和 UI 完善按 owner 要求独立处理：真实使用习惯下的登录/退出/改密、命名/解绑、多节点选择与账号切换；未遍历的 UI/权限/辅助功能组合；首次摄像头授权后需要再次点击开始的体验。已通过的自动化与本轮实际真机检查不再要求复验。

Win7、其他 GPU/DPI/Android 机型、生产完整报警链与长期运行另行安排；不把发布、安装及公网接口通过扩写为这些场景已通过。
