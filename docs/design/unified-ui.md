# Web 与通知节点界面

Web 承担统一查看与管理节点；通知节点接收告警并在本机播放。两者使用相同的颜色、字号层级、列表与表单风格，浅色与深色跟随系统。

## 视觉与布局

| Token | 浅色 | 深色 |
|---|---|---|
| 页面 | `#F5F7F8` | `#10191B` |
| 面板 | `#FFFFFF` | `#172326` |
| 主文字 | `#172326` | `#EDF4F5` |
| 次文字 | `#66777A` | `#9AADB1` |
| 分隔线 | `#DFE6E7` | `#2C3A3D` |
| 强调 | `#087F83` | `#4FBCC1` |
| 选中背景 | `#E2F1F2` | `#113437` |

- 使用系统中文无衬线字体。页面标题 26、分区 18–20、正文 14–15、辅助信息 12–13；常规字重，标题与主要动作适度加粗。
- 间距按 4 / 8 / 12 / 16 / 24 / 32，面板圆角 8–12，细边框，无渐变与装饰图表。状态同时用文字和颜色说明。
- Web 平板和电脑保留侧栏、列表和详情，手机使用顶部导航及列表/详情切换；通知节点使用接警面板、连接弹窗及独立历史/铃声库页面。长内容滚动，大字体保留按钮可达。
- Web 的来源参数在来源停止后调整；控件按能力、在线状态和实际可修改条件启用。未上报的配置不作为实际值展示。
- VisionGuard 通知节点只有 VG 接警开关。声音使用持久化队列与有限播放设置；达到次数自动结束，用户也可确认停止。
- 页面仅展示真实连接、配置和记录。无节点、无记录或未配置时使用明确空状态，不自动填入示例节点。

## 实现与取证

Web 的组件和 CSS token 位于 `receiver/web/`；通知节点的 Compose theme 与界面位于 `notifier/android/`。既有启动器位图保持原样。一次性参考图和截图在被忽略的 `.local/ui-concepts/`，不作为运行资源。
