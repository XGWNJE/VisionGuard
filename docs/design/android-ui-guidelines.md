# VisionGuard Android UI 规范

三个 Android 组件的账号界面和基础主题统一使用 [`android-shared/`](../../android-shared/) 的现代简约青色方案，与当前 Web 控制台、通知节点保持一致。控制台保留现有警报与设备布局；镜头推流、通知节点分别保留各自的主任务。Windows 视觉推理节点暂不重做整体外观。

## 风格与颜色

页面优先显示连接、推流或接警状态及一个明确的主操作。使用轻边框、简单圆角、稳定字号和留白，复杂设置放在相关上下文中；不添加装饰性背景、默认动态紫色主题或营销内容。

| 语义 | 浅色 | 深色 |
|---|---|---|
| 主色 | `#087F83` | `#4FBCC1` |
| 页面背景 | `#F5F7F8` | `#10191B` |
| 表面 | `#FFFFFF` | `#172326` |
| 次级表面 | `#EFF3F4` | `#203033` |
| 正文 | `#172326` | `#EDF4F5` |
| 辅助文字 | `#66777A` | `#9AADB1` |
| 轻边框 | `#DFE6E7` | `#2C3A3D` |

跟随系统浅深色。镜头持续推流时可主动使用暗色、降低当前窗口亮度及收起预览；状态与停止按钮仍可见。

## 共同组件

- 登录页只要求账号、密码与本机名称；服务地址放在可展开的测试设置。身份登记、令牌与匹配通道由程序处理，不作为用户输入。
- 登录后的账号条显示账号与设备名，提供退出和修改密码；修改密码明确提示其他设备须重新登录。
- 共同主题采用 28sp/34sp 主标题、20sp/26sp 模块标题、16sp/24sp 正文与 14sp/18sp 标签；不随视口尺寸动态缩放。
- 输入框和操作保留明确标签与触摸区域，主按钮约 50dp 高；内容可滚动，小屏和输入法展开时不裁切。
- 通用表面圆角为 12/16/24/28dp；既有控制台卡片保留其现有参数。图标优先使用已有 Material 图标库。
- 在线与主操作使用青色，辅助与离线使用灰色，连接中/未就绪使用琥珀色，报警与危险操作使用红色。控件禁用与失败原因必须可见。

## 主任务结构

- **VisionGuard 镜头推流**：目标视觉节点、实时预览、开始/停止、画面规格、暗色省电与收起预览。切后台/锁屏后正常停止，回到前台手动恢复；服务器确认文案不得表示推理完成。
- **VisionGuard 控制台**：保持 `警报 / 设备` 两个主 Tab，报警截图在详情页按需加载；设备名单取自账号登记，实时连接和来源状态由服务端推送；首次登录也能查看离线镜头。离线设备解绑必须确认并撤销服务端登记，事件记录保留。设备控制根据服务端能力显示，镜头推流不能展示模型/推理参数操作。
- **VisionGuard 通知节点**：连接状态、接收范围、声音策略、最近报警和历史。账号取代手填节点凭据，有限播放及确认停止保留。

控制台当前顶部状态条、底部浮动导航、设备卡和参数 sheet 继续按源码中的布局参数维护，列表需预留浮层空间。颜色调整不作为所有真实设备已目检通过的证据。

## 验证入口

三个 Android 工程按影响运行 `:app:testDebugUnitTest`、`:app:lintDebug` 和 `:app:assembleDebug`，发布产物另做签名 Release 构建。账号、帧确认和前后台策略先做自动化验证。

可见模拟器用于交互、布局和测试素材链路取证；浅深色、大字号、旋转及厂商行为仍留在当前[验证台账](../codex/90-verification-report.md)中，由 owner 集中验收。Windows 外观不属于本轮 UI 改造范围。
