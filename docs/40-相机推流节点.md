# 相机推流节点

负责：相机推流节点（Android 与 Web）。不负责：其他模块事实、任务状态或重复验证记录。更新时机：该主题源码或约束变化时；历史发行说明只纠正事实，不随当前版本改写。


相机推流节点属于视觉节点类型（`visual`），有两个平台实现：Android 应用 `detector/android/` 和 Web 页面 `detector/web/`。两者都在前台采集摄像头画面，经统一服务转发给账号内的视觉推理节点；本机不加载模型、不执行目标推理或生成视觉报警。应用名与安装身份见[命名规范](15-命名规范.md)。

## 界面与字体

- 单页按设备身份与连接状态 → 本机入队／服务收帧及两端丢弃 → 目标与设置 → 启停组织；横屏左控制右预览（约 3:2），竖屏上控制下预览（约 1.7:1）。内容不足时区内滚动，启停固定可见；关闭预览保留区域，画面始终等比显示。
- Web 直接复用控制台官方 shadcn/ui Neutral／Radix Nova 组件与 `receiver/web/src/theme.css`；Android 保留 Compose，使用共享控制台主题。均提供跟随系统／浅色／深色，目标弹窗展示完整名称后确认关联，帮助、账号与外观从顶部进入。
- Android 默认进入沉浸全屏，隐藏系统状态栏和导航栏；帮助及账号全屏弹窗保持同一行为，边缘滑动可临时调出系统栏。Web 按[浏览器全屏规则](https://fullscreen.spec.whatwg.org/)在首次点击或 Enter／空格时请求全屏，顶部可切换，主动退出后不强制重进；不支持或拒绝时保留正常页面。
- 两个相机端独立内置 **Noto Sans Simplified Chinese**，涵盖登录、主界面及应用弹窗，不依赖设备安装或外部字体请求。Web 使用锁定的 `@fontsource-variable/noto-sans-sc@5.3.1` WOFF2 分片，Android 使用完整可变 TTF，均为 `2.004-H2`、100–900 字重；系统权限与安装器使用系统字体。
- Android 字体来自 [Google Fonts 固定提交](https://github.com/google/fonts/blob/a85815a42757630ce188fdad368c2dfc444d4773/ofl/notosanssc/NotoSansSC%5Bwght%5D.ttf)，SHA256 为 `a3041811a78c361b1de50f953c805e0244951c21c5bd412f7232ef0d899af0da`；两端随包分发 SIL OFL 1.1 许可。其他项目组件字体本轮不变。

## 共同契约

- 账号密码登录，服务器自动登记本机身份；同账号只有一个兼容推理节点时自动关联，多个时按名称选择。
- 控制与视频分别使用 `/ws` 和 `/media/ws`；二进制帧包含 4 字节大端 JSON 头长度、UTF-8 头和 JPEG。
- 头携带服务器分配的流 ID、媒体会话 ID、递增序号、采集时间、宽高和方向；单帧 JPEG 上限 2 MiB、头上限 4096 字节，JPEG 宽高必须与头一致、方向只能是 0 / 90 / 180 / 270。
- 采集时间使用本机单调时钟，发送前丢弃超过 2.5 秒的帧；中继按每连接时钟偏移和接收间隔检查，跳变后重连，不假设跨设备时钟同步。
- 允许最多 8 帧、合计 2 MiB 加帧头在途，回执异步确认累计进度；额度不足时在转换 / 压缩前跳过当前画面，最早在途帧超过 3 秒无确认则重连。
- 绑定来源开始检测后按其配置的 1–5 FPS 转换 / 压缩 / 发送，来源暂停后降至 1 FPS，未收到目标快照前默认 5 FPS；媒体空闲时也发送心跳，12 秒无响应重连。
- 相机端声明 `video-publish`、`stream-control`、`camera-config` 能力，不声明本地推理、模型或参数控制能力；不产生“连接中断 / 检测运行中断”事件。
- 页面以“本机入队／服务收帧”分别显示发送队列接纳和服务收件，本机丢弃与服务丢弃独立显示；主动限帧未采样单列。服务统计为当前运行期累计，不落盘。
- 用户主动停止或离开前台是正常停流；意外断网、媒体连接失效和画面停滞属于故障。服务确认只表示中继收到这帧，不代表推理节点已完成推理。
- 控制台可远程修改规格、预览与亮度开关，读回节点持久配置；摄像头授权、解锁与前台条件须在本机满足，远程开始推流不能绕过。

## Android 实现（`detector/android/`）

- 显示名为 **相机推流节点**，工程目录和包名是 `detector/android/` 与 `com.xgwnje.visionguard.detector`；服务器按登录组件 `android-camera` 分配 `detector / visual / android` 身份。
- 顶部显示应用与本机名称、帮助／设置／账号入口；控制卡含状态、两列关键统计、独立丢弃数、目标、原生分段规格选择及窗口亮度开关。预览开关位于预览卡标题，主要操作触控区域至少 48dp。
- 主界面只保留必要状态、数值和操作；帮助页显示主动未采样及采集／发送尺寸。账号、外观、更新入口复用共享组件。
- 真实 CameraX `ImageAnalysis` 采集，JPEG 二进制媒体 WebSocket 推流。
- 默认最高 640×480、5 帧/秒，可切换到最高 1280×720；高规格优先选择 16:9，相机不支持时使用可用规格。主界面显示真实发送尺寸与回退标识，帮助页查看采集 / 发送尺寸；输出超过选择上限时缩放，视频最大长边 1280、短边 720。
- 摄像头生命周期绑定当前 Activity；切到后台或锁屏立即停流、解绑摄像头。回到前台须手动开始。
- 横竖屏与窗口尺寸变化由当前 Activity 处理，Compose 更新布局，保留相机绑定、目标与媒体会话；按当前屏幕方向动态更新 CameraX 目标旋转，包含系统支持的 180° 翻转。本机预览与媒体帧共用每帧的旋转信息；方向遵循系统屏幕旋转，不强制绕过旋转锁定。
- 首次请求相机权限保留本次用户启动操作，授权成功且页面恢复前台后只启动一次；拒绝授权或 Activity 真正停止则取消请求。未推流时的权限弹窗不改写为后台停流状态。
- 仅推流时保持亮屏；应用内可单独降低窗口亮度、收起画面预览。跟随系统／浅色／深色选择持久保存，与推流亮度独立；系统状态不可用时回退浅色。停止后恢复窗口亮度，不修改系统锁屏或唤醒设置。
- YUV 各平面按行批量读取，分别处理行距、像素步长和起始偏移，再转为 NV21；不假设 U/V 共享内存。JPEG 质量保持 55，超过规格上限才缩放。采样采用固定节拍吸收相机回调抖动，长时间停顿后不突发补帧。
- 重复绑定同一目标保留媒体会话、帧序号与在途额度；新连接使用自己的期限，旧回调不能清理新连接。
- 启动与手动检查 GitHub 稳定版更新，精确选择相机 APK；下载支持取消、大小／SHA256、包名／版本／签名校验与私有缓存暂存。安装前后台复核并要求应用处于前台，损坏缓存退回下载；退出时网络清理也在后台执行。允许安装后请求系统安装器，不把请求或打开安装器显示为已安装。

## Web 实现（`detector/web/`）

- 同源页面 `/camera/`，工程与 npm 标识 `visionguard-web-camera`；服务器按登录组件 `web-camera` 分配 `detector / visual / web` 身份，默认名称为“相机推流节点 · 浏览器平台标识”。
- **必须运行在安全上下文**：浏览器只在 HTTPS（或本机 `localhost`）提供摄像头；明文私网地址不弹授权弹窗，页面直接提示改用 HTTPS。这是与 Android 实现最主要的部署差异。
- 页面与 Android 共享信息顺序，增加 Web 摄像头选择；窄屏顶部操作收进“更多操作”。按钮、下拉和弹窗关闭操作至少 48 CSS px，弹窗支持 Escape 与可见触发按钮焦点恢复，保留安全区域和字号缩放。
- 采集使用 `getUserMedia`（默认后置优先，可指定摄像头），画面绘制到画布后以 JPEG 质量 55 编码；编码结果先按服务端契约自检（EOI 结尾、SOF 宽高与目标尺寸一致），不合格的帧直接丢弃并计数，不会把连接打死在中继的 `invalid frame` 校验上。
- 尺寸与服务端一致：长边最大 1280、短边最大 720，超出时等比缩放，不做放大；浏览器已转正画面，方向固定上报 0，横竖屏由宽高表达。
- 页面隐藏或锁屏立即停流并释放摄像头轨道，回到页面须手动开始；浏览器会暂停后台标签页，因此不做后台保活。
- 浏览器亮度无法由页面控制系统设置，`cameraDimScreen` 仍可远程写入并保存，但页面只提示由系统控制，不做视觉动作。
- 设备身份按源保存在独立 IndexedDB，不按型号或 UA 指纹；规格与预览开关保存在本机存储，控制台远程配置写入同一入口。
- 权限拒绝、无可用摄像头、摄像头被占用、网络中断和媒体停滞分别有明确状态，且与本机推流状态独立显示。

## 账号与身份

登录只填写账号密码；Android 用 Keystore／AES-GCM 按服务和组件加密记住账号密码，退出时撤销服务会话；Web 不保存密码，按会话保存令牌，退出清除当前标签页会话。Android 会话与记忆排除系统备份和设备转移。Release 内置正式服务地址，Debug 才显示本地服务设置；UI 预览构建（`.uipreview`）额外内置本地服务通道、局域网地址与预览账号，启动先在局域网发现服务并静默登录，登录页的「本地服务设置」可勾选停在登录界面调登录流程（之后每次启动清除本机会话）。Web 本地预览也免登录：隔离实例经 `GET /api/account/preview-signin`（仅回环请求）把预览账号交给页面，地址带 `?login` 则停在登录页；控制台「设置 → 常规设置」提供入口。默认设备名称遵循[命名规范](15-命名规范.md)，Android 账号菜单及控制台可修改本机名称。

## 维护入口

- Android 采集、前后台状态与亮度：`detector/android/app/src/main/java/com/xgwnje/visionguard/detector/MainActivity.kt`；主页面与帮助：同目录 `CameraHome.kt`
- Android 媒体连接、帧确认与目标绑定：同目录 `stream/CameraPublisher.kt`；YUV 转换与规格限制：`stream/YuvPlanes.kt`、`stream/CameraFrameCodec.kt`、`stream/MediaPacket.kt`
- Android 账号与共享主题：`android-shared/src/main/java/com/xgwnje/visionguard/account/`；相机字体与主题：`detector/android/app/src/main/java/com/xgwnje/visionguard/detector/ui/theme/Theme.kt`
- Android 编译与签名：`detector/android/app/build.gradle.kts`；不限制为单一 ARM ABI，支持本机 x86_64 模拟器构建。
- Web 控制通道与远程配置：`detector/web/src/control.ts`；媒体通道：同目录 `media.ts`、`mediaPacket.ts`
- Web 采集与编码：`detector/web/src/cameraSource.ts`；消息契约与校验：`protocol.ts`；本机身份与设置：`device.ts`；页面与组件：`main.tsx`、`CameraInterface.tsx`、`style.css`
- 服务端发布白名单与流分配：`server/src/services/NodeComponents.ts`、`MediaRelay.ts`；页面挂载：`server/src/index.ts`

## 验证边界

构建、模拟器链路与未覆盖项以[验证报告](90-验证记录.md)为准。模拟器的视频摄像头不证明真实老手机的功耗、镜头画质、厂商管理或硬件编码能力；桌面浏览器的摄像头也不证明移动端浏览器的编码性能、后台挂起行为或厂商浏览器差异。镜头收到服务器确认也不等于完整报警链验收。

Web 控制台可开始／停止两个实现的推流；开始必须已有推理目标、摄像头权限且相机保持前台，Web 还要求页面处于安全上下文与前台。回执在实际相机绑定完成后发送，只证明相机启动，实际收帧与推理由媒体状态核实；离线或缺少本机授权时不能远程绕过。
