## 维护原则

- README 面向用户和开发者，维护项目介绍、组件入口和常用命令。
- AGENTS.md 维护项目操作规则、稳定约束、按需阅读入口和授权边界。
- 验证报告维护自动化、人工和真机证据；各模块专题维护当前实现事实与有效约束。
- 实现事实以源码为准；证据范围以验证报告为准；操作与授权以 AGENTS.md 为准。
- 每项验证写明范围和限制；编译、帧循环、FPS、界面启动和图片读取不能替代业务语义验收。
- 版本号、发布脚本、模型文件名不要在未授权情况下改动；验证报告保留最近三个发行版本的完整证据及当前专项；更早证据汇总，原始资料不自动删除。任务清单只保留未完成事项和仍存在分支的归属，不追加已完成步骤。
- 修改文档、入口、版本、正式域名或产品边界后运行 `node scripts/check-docs.js`；新增专题文档只登记到本索引；发行说明只登记在 `releases/README.md`。README 和 AGENTS 按使用需要链接，不维护全量清单。
